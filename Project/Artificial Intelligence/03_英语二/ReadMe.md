## 学习顺序
1. 词汇：每天复习旧词并学习新词，记录词性、核心义、搭配和真题语境。
2. 语法：识别句子主干、从句边界、非谓语结构和特殊句式。
3. 长难句：断句—找主干—识别修饰—逐层翻译—通顺重写。
4. 阅读：先独立做题，再定位原文证据，分析干扰项。
5. 新题型与翻译：训练篇章逻辑、指代关系和语义准确性。
6. 写作：建立功能句素材库，练习结构、内容和语言准确性。
7. 完形：结合上下文逻辑、词汇搭配和语法线索。

## 阅读错题标签
定位错误、同义替换不识别、主旨偏差、推断过度、词义误判、句法结构误判、干扰项排除失败、时间分配不合理。

练习材料优先使用合法获取的真题与自编例句；不整篇转载受版权保护的文章或解析。
