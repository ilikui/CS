## 三、学习阶段

1. **基础阶段**：先建立高频词汇与基本句法框架；阅读短段落，做到能找主谓宾、识别从句。
2. **强化阶段**：进入真题训练；每道题必须能指出原文证据、逻辑关系和错误选项的问题。
3. **冲刺阶段**：按考试节奏完成整套训练；重点修复高频失分点，不盲目追求偏词难句。

## 四、单次训练闭环

1. 限时独立完成任务，不先看解析。
2. 标记答案依据：原文句、语法结构、上下文逻辑。
3. 复盘错误类型：知识缺口、定位偏差、推理过度、表达不准确或时间失控。
4. 将可复用内容沉淀为词汇卡、句型卡、题型策略卡。
5. 1 天、3 天、7 天后回看错题与素材。

## 五、每日最小任务

- [ ] 复习旧词并学习新词，记录搭配而非只背中文释义
- [ ] 拆解 1 个长难句
- [ ] 完成 1 组阅读/翻译/写作微任务
- [ ] 复盘至少 1 个错误或不确定选项
- [ ] 将高价值内容写入笔记并安排复习

## 七、笔记规范

每条知识至少包含：**知识点、判断依据、例句/题目、错误提醒、复习状态**。真题文章及商业教辅解析应通过合法渠道获取；本仓库以自编例句、方法总结和个人错题为主，不整篇转载受版权保护的材料。
