# 写作｜应用文与图表作文训练

## 一、写作的基本评价维度
审题与任务完成、内容覆盖、结构连贯、词汇准确、语法正确、拼写与标点。复杂表达不是目标，准确、清楚、切题更重要。

## 二、审题清单
- 写作对象是谁？写给谁？
- 写作目的是什么：请求、邀请、感谢、道歉、建议信、通知或介绍？
- 题目要求包含哪几个信息点？
- 语气应正式、半正式还是友好？
- 是否需要标题、称呼、落款？以题目要求为准。

## 三、应用文通用结构
1. **开头**：说明写信目的。
2. **主体**：逐点完成题目要求，每段一个主要信息。
3. **结尾**：提出期待、感谢或后续安排。
4. **格式**：称呼、正文、结束语与署名保持一致。

## 四、常用表达（按功能记忆）
| 功能 | 表达 |
|---|---|
| 写信目的 | I am writing to ... |
| 提出建议 | One practical solution would be to ... |
| 表达感谢 | I sincerely appreciate your ... |
| 表达歉意 | I apologize for ... |
| 邀请 | I would be delighted if you could ... |
| 提供帮助 | Please feel free to contact me if ... |
| 期待回复 | I look forward to hearing from you. |
| 图表概述 | The chart illustrates changes in ... |
| 描述趋势 | The figure increased steadily from ... to ... |
| 对比 | By contrast, ... |
| 解释原因 | Several factors may account for this trend. |

## 五、图表作文组织方式
- 第一段：准确描述图表主题、对象、时间范围和主要趋势。
- 第二段：分析有依据的原因或影响，避免把猜测写成事实。
- 第三段：总结趋势、提出审慎建议或展望。
- 数据表达：区分 increase by（增加了）与 increase to（增加到）；区分 percentage 与 percentage points。

## 六、自编写作练习
**题目：** 你校计划举办一次关于数字学习的经验交流活动，请写邮件邀请一位同学参加，并说明活动主题、时间地点及邀请原因。

**构思：** 开头发出邀请；主体交代主题、时间地点、活动内容；结尾说明期待对方参加。

**自查：** 是否覆盖所有信息点？时态是否一致？是否有中式表达？每句话是否承担明确功能？

## 七、修改流程
先检查任务信息是否完整，再检查段落逻辑，然后检查动词时态、主谓一致、冠词、介词、单复数、拼写和标点。不要为了“高级”而使用不熟悉且无法保证正确的句型。
