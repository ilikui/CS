# 翻译与新题型｜句间关系与语篇重构

## 一、英译汉五步法
1. **找主干**：确定主语、谓语、宾语/表语。
2. **拆修饰**：将定语、状语、同位语、插入语分层。
3. **辨逻辑**：明确转折、因果、让步、条件、递进和对比。
4. **定指代**：确认 it、they、this、which、such 等具体指向。
5. **中文重组**：在不改变逻辑和信息的前提下调整语序，避免逐词硬译。

## 二、常见翻译难点
- 抽象名词：the availability of resources 可根据语境译为“资源是否充足/资源的可获得性”。
- 被动语态：不必机械保留“被”，可转为主动或无主句。
- 名词化结构：make an improvement → “有所改进/进行改进”。
- 长定语：拆成短句或前置为中文定语，避免层层嵌套。
- 代词指代：先还原指代对象，再组织译文。

## 三、新题型的篇章线索
- **指代**：this/these/such/they 必须能在上下文找到指向。
- **复现**：同义词、近义表达、上义词与下义词形成主题链。
- **连接词**：however 表转折；therefore 表结果；for example 表举例；moreover 表递进。
- **语义连贯**：代入后检查主题是否一致、逻辑是否自然、语法是否成立。
- **段落功能**：定义、提出问题、解释原因、举例、反驳、总结。

## 四、段落排序/匹配的操作步骤
1. 先读各段首尾句，提取主题词。
2. 寻找明显的指代、连接词和时间顺序线索。
3. 判断定义—解释、观点—论据、问题—解决方案等关系。
4. 建立候选顺序后通读验证，不凭单一词汇决定。
5. 检查代词是否有先行项、转折是否有前文、例子是否有论点。

## 五、自编练习
将句子按逻辑排序：
A. As a result, they may become more confident in evaluating online claims.
B. Students first need opportunities to compare information from different sources.
C. Such practice can help them recognize unsupported statements.

**参考顺序：B → C → A。** B 引入练习；Such practice 回指比较信息；As a result 引出结果。

## 六、翻译评分自查
- 信息是否完整，有无漏译？
- 主谓关系、否定、比较、范围是否准确？
- 逻辑连接是否保留？
- 中文是否通顺自然？
- 是否擅自添加原文没有的信息？
