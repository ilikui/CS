# 基础句法框架｜长难句的底层语法

## 一、五种基本句型
| 句型 | 结构 | 示例 |
|---|---|---|
| 主谓 | S + V | Prices increased. |
| 主谓宾 | S + V + O | Researchers examined the data. |
| 主系表 | S + linking V + C | The result seems reliable. |
| 主谓间宾直宾 | S + V + IO + DO | The study gave readers an answer. |
| 主谓宾宾补 | S + V + O + OC | The policy made services more accessible. |

## 二、句子成分识别
- 主语：句子谈论的对象。
- 谓语：限定动词结构，表达动作或状态。
- 宾语：动作涉及的对象。
- 表语：说明主语状态或性质。
- 定语：修饰名词。
- 状语：修饰动词、形容词、副词或整个句子。
- 补语：补充说明主语或宾语。

## 三、从句识别
- 名词性从句：在句中充当名词性成分。
- 定语从句：修饰名词或代词。
- 状语从句：表示时间、原因、条件、让步、目的、结果等。

## 四、时态与语态速查
| 形式 | 基本构成 | 主要含义 |
|---|---|---|
| 一般现在 | do/does | 事实、习惯、一般规律 |
| 一般过去 | did | 过去发生的动作或状态 |
| 现在完成 | have/has done | 过去动作与现在的联系 |
| 过去完成 | had done | 过去某一时间之前已完成 |
| 进行时 | be doing | 某时正在进行 |
| 被动语态 | be + done | 强调承受动作的对象 |

## 五、非谓语动词
- to do：常表示目的、将来倾向或特定动词后的补足成分。
- doing：常表示主动、进行或名词性动作。
- done：常表示被动或完成状态。
判断时要结合逻辑主语、时间关系和句法位置，不能只靠形式机械翻译。

## 六、自测
Identify the main clause: **What matters most is that students learn how to evaluate evidence.**
- 主句主干：What matters most is...
- What 引导主语从句；that 引导表语从句；how 引导 learn 的宾语从句。
- 译文：最重要的是，学生要学会如何评估证据。
