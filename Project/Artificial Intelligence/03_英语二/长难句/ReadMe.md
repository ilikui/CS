# 长难句｜句法拆解与准确翻译

## 一、拆句总流程

~~~mermaid
flowchart TD
 A[通读句子] --> B[圈出谓语动词]
 B --> C[确定主句主谓宾/主系表]
 C --> D[标出从句边界]
 D --> E[识别非谓语与介词短语]
 E --> F[还原指代和逻辑关系]
 F --> G[逐层翻译并调整中文语序]
~~~

## 二、先找谓语，再找主干
- 一个独立分句通常有自己的限定谓语；并列句、主从复合句中可能出现多个谓语。
- 情态动词、助动词与实义动词共同构成谓语，如 *may have been overlooked*。
- 非谓语动词（to do、doing、done）本身不充当限定谓语，但可以作主语、宾语、定语、状语或补语。
- 识别连接词：that、whether、if、who、which、when、because、although、while 等。

## 三、核心结构清单

| 结构 | 识别线索 | 翻译重点 |
|---|---|---|
| 定语从句 | 先行词 + who/which/that/whose/关系副词 | 明确修饰对象，必要时拆译 |
| 名词性从句 | that/what/whether/疑问词引导 | 整体作主语、宾语、表语或同位语 |
| 状语从句 | because/although/if/when/while 等 | 明确因果、让步、条件、时间 |
| 非谓语 | to do / doing / done | 判断逻辑主语与主动/被动、时间关系 |
| 同位语 | 名词后的解释性成分 | 可译为“即……/也就是……” |
| 插入语 | 逗号、破折号、括号 | 先暂时移除，抓住主干 |
| 倒装/强调 | 助动词提前、It is...that... | 还原正常语序理解 |

## 四、典型拆解示范（自编例句）

**句子：** Although digital tools can make information easier to access, the ability to judge whether that information is reliable remains essential.

1. 找谓语：can make；remains；is。
2. 主句：the ability remains essential。
3. 让步状语从句：Although digital tools can make information easier to access。
4. whether 引导宾语从句，作 judge 的宾语。
5. 结构：Although [让步从句], [主语 the ability] [谓语 remains] [表语 essential]。
6. 译文：尽管数字工具能够让信息更容易获取，但判断这些信息是否可靠的能力仍然至关重要。

## 五、易错点
- 不要把 that 一律译成“那个”：它可能引导名词性从句或定语从句。
- which 可能指代前面整件事，不一定只指最近的名词。
- with + 名词 + 分词/形容词/介词短语常作独立主格或伴随状语。
- not...until、rather than、more...than 等结构要先判断逻辑关系。
- 长定语可先定位中心名词，再逐层处理修饰成分。

## 六、练习方法
每天选 1—2 句：抄句子 → 标谓语 → 划从句 → 找主干 → 标修饰关系 → 翻译 → 对照检查遗漏的逻辑关系。每周回看最容易误判的结构。
