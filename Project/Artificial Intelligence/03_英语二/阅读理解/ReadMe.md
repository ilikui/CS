# 阅读理解｜证据驱动的解题体系

## 一、核心原则
**答案必须有文本证据。** 不用生活常识替代文章信息；不把作者未表达的观点扩展成自己的推论。

## 二、做题流程
1. 快速浏览标题、首段、段首句和结尾，形成文章主题假设。
2. 读题干，圈出对象、范围、时间、比较关系和限定词。
3. 回原文定位同义表达，不只搜索题干原词。
4. 精读证据句及其上下文，判断句间逻辑。
5. 对照选项：保留与原文等值的表达，排除偷换概念、范围扩大、因果倒置和无中生有。
6. 做完后复盘：题型、证据句、同义替换、干扰项陷阱。

## 三、常见题型与策略

| 题型 | 识别方式 | 解题抓手 |
|---|---|---|
| 细节题 | according to / indicate / mention | 定位原文，逐项核对 |
| 主旨题 | mainly about / best title | 综合全文，不以单段代替全文 |
| 推断题 | infer / suggest / imply | 只做一步或必要的有限推断 |
| 词义题 | closest in meaning | 用上下文、词性和逻辑替换验证 |
| 态度题 | attitude / tone | 关注评价词、情态动词和转折 |
| 例证题 | example / case / study | 例子通常服务于其前后的论点 |
| 目的题 | why does the author mention | 说明该信息在论证中的功能 |

## 四、常见干扰项
- **偷换主体**：原文谈研究者，选项改成公众。
- **范围扩大/缩小**：some 改成 all；短期改成长期。
- **程度绝对化**：may 改成 must；often 改成 always。
- **因果倒置**：把结果说成原因。
- **无中生有**：选项看似合理，但文章没有依据。
- **断章取义**：单句似乎支持，结合上下文却不成立。
- **比较对象错位**：比较 A 与 B，选项却比较 A 与 C。

## 六、自编微练习
**Passage:** Some schools have introduced later start times. Supporters argue that additional sleep can improve students' attention, while critics point to transport costs and scheduling difficulties.

**Question:** What is the passage mainly concerned with?
A. The proven failure of later school start times.
B. Different considerations surrounding later school start times.
C. The elimination of transport costs in schools.
D. A universal rule for school schedules.

**答案：B。** 文段呈现支持者与反对者的不同考虑。A 将讨论写成已证实失败；C 原文未说成本被消除；D 无“普遍规则”的信息。
