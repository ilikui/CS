# 完形填空｜语篇逻辑与词汇辨析

## 一、解题核心
完形填空不是逐空孤立选词，而是利用**篇章主题、句间逻辑、语法结构、固定搭配和词义辨析**共同确定答案。

## 二、推荐流程
1. 首轮通读全文，抓主题、人物/对象、态度和叙述方向。
2. 先做有明确语法或固定搭配线索的空。
3. 回到上下文判断逻辑：因果、转折、递进、让步、解释或举例。
4. 比较选项的词义、词性、搭配和语气强度。
5. 全文代入复读，检查指代、时态、语义连贯。

## 三、线索分类
| 线索 | 常见信号 | 判断方法 |
|---|---|---|
| 转折 | but, however, yet, although | 前后语义方向相反或形成让步 |
| 因果 | because, therefore, thus, consequently | 原因与结果相互匹配 |
| 递进 | moreover, furthermore, additionally | 后项补充或加强前项 |
| 对比 | while, whereas, unlike | 比较双方的差异 |
| 举例 | for example, such as | 例子解释前面的概括 |
| 复现 | 同义词、近义表达、上下义词 | 主题词在篇章中形成语义链 |

## 四、词汇辨析四问
1. 选项在当前句子中词性是否正确？
2. 与前后名词、动词或介词是否构成自然搭配？
3. 词义是否符合上下文逻辑？
4. 语气强度是否与作者态度一致？

## 五、自编练习
**Passage:** Public libraries remain valuable in the digital age. They not only provide access to books but also create spaces where people can learn together. For this reason, many communities continue to ___(1)___ in library services.

(1) A. invest  B. avoid  C. confuse  D. divide

**答案：A。** invest in 表示“投资于”。后文说明图书馆仍有价值，社区继续投入服务符合语义。其余选项与语境不符。

## 六、错题复盘
记录空格所在句、前后文线索、正确选项的搭配、其他选项不成立的原因。若只记中文释义而不记录语境，下次仍容易重复出错。
