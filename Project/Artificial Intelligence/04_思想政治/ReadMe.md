## 复习策略
1. 基础阶段：建立章节框架，理解概念、原理和历史脉络。
2. 强化阶段：围绕易混概念、原理辨析和材料分析组织专题。
3. 冲刺阶段：结合当年时政与模拟题，训练选择题判断和主观题表达。
4. 考前阶段：回顾错题、核心概念和高频材料，不以背诵代替理解。
