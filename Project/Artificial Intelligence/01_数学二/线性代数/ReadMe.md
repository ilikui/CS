## 章节知识清单

### 1. 行列式
- 行列式定义、按行/列展开与基本性质。
- 交换两行（列）、某行（列）提出公因子、倍加变换对行列式的影响。
- 特殊行列式：上/下三角、范德蒙德型等。
- 方阵可逆当且仅当行列式不为零。

### 2. 矩阵
- 加法、数乘、乘法、转置与幂；伴随矩阵、逆矩阵及其性质。
- 初等矩阵、初等行变换与矩阵秩。
- 分块矩阵的基本运算。

### 3. 向量组
- 线性组合、线性表示、线性相关与线性无关。
- 向量组等价、极大线性无关组、向量组的秩。
- 线性相关性的判定与证明。

### 4. 线性方程组
- 齐次方程组 $Ax=0$ 与非齐次方程组 $Ax=b$。
- 有解当且仅当 $r(A)=r(A|b)$。
- 齐次方程组基础解系、解空间维数 $n-r(A)$。
- 非齐次通解 = 一个特解 + 对应齐次方程组通解。

### 5. 特征值与特征向量
- 特征方程 $|\lambda I-A|=0$。
- 特征值、特征向量的求法及性质。
- 相似矩阵的不变量：特征多项式、行列式、迹、秩。
- 可对角化条件；不同特征值对应的特征向量线性无关。
- 实对称矩阵可由正交矩阵正交相似对角化。

### 6. 二次型
- 二次型与对称矩阵表示 $f(x)=x^TAx$。
- 正交变换、配方法与合同变换。
- 惯性定理、规范形与标准形。
- 正定矩阵判定：定义法、顺序主子式法（注意适用条件）。

## 核心联系

- 行列式非零 ⇔ 方阵可逆 ⇔ 满秩。
- 矩阵秩决定线性方程组解空间维数。
- 特征值之和等于矩阵的迹，特征值之积等于行列式（按代数重数计）。
- 实对称矩阵特征值为实数，不同特征值对应的特征向量正交。
- 正定二次型 ⇔ 对应对称矩阵正定。

## 常见失分点

1. 混淆矩阵等价、相似、合同，它们保持的不变量不同。
2. 用行列变换处理矩阵时，忘记行列式变换规则。
3. 齐次方程组有非零解的条件是 $r(A)<n$。
4. 只会求特征值，不会利用迹、行列式、秩和特征向量性质。
5. 正定判别时不检查矩阵是否为实对称矩阵。
6. 二次型变量替换与矩阵变换方向容易写反。

## 练习建议

- 基础：行列式计算、矩阵秩、线性相关判定、方程组求解。
- 强化：参数讨论、向量组与方程组综合、相似对角化、二次型正定性。
- 冲刺：按真题题型限时训练，归纳“条件—结论—所用定理”。
