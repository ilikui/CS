## 常考计算与分析
- 奈奎斯特/香农：判断题目给的是无噪声带宽限制还是有噪声信道容量。
- CRC：按生成多项式进行模 2 除法，异或不借位、不进位。
- 滑动窗口：区分发送窗口、接收窗口、序号空间和确认号。
- 子网划分：写出网络位、主机位、掩码、网络地址、广播地址和可用地址范围。
- 路由：最长前缀匹配；区分路由选择与分组转发。
- TCP：序号按字节计数；SYN/FIN 各消耗一个序号；确认号表示期望收到的下一个字节。
- 拥塞控制：区分慢开始、拥塞避免、快重传、快恢复及触发条件。

## 高频易错点
- OSI 七层与 TCP/IP 层次映射不能机械等同。
- 交换机依据 MAC 地址转发，路由器依据网络层信息转发。
- ARP 解决 IP 地址到链路层地址的映射，不负责跨网段路由。
- TCP 流量控制面向接收方缓存，拥塞控制面向网络负载。
- DNS 递归查询与迭代查询要结合客户端和服务器角色分析。
- HTTP 是应用层协议；可靠传输由下层协议提供。
