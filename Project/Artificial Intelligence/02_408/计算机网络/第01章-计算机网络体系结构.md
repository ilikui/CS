# 第 01 章｜计算机网络体系结构

> 本章目标：掌握网络的组成、分类、性能指标、协议三要素以及分层体系结构，能解释封装/解封装、服务与协议的区别。

## 1. 计算机网络的组成与功能

计算机网络通过通信链路和交换设备连接自治计算机系统，实现数据通信与资源共享。

### 1.1 组成角度

- **组成部分**：主机（端系统）、通信链路、交换设备、网络协议。
- **工作方式**：边缘部分负责信息处理与应用；核心部分负责数据交换与转发。
- **功能组成**：通信子网负责数据传输；资源子网提供计算、存储和应用资源。

### 1.2 网络的主要功能

1. 数据通信：在端系统之间传送信息。
2. 资源共享：共享硬件、软件和数据。
3. 分布式处理：多个系统协作完成任务。
4. 提高可靠性：通过冗余路径和服务部署降低单点故障影响。
5. 负载均衡：把任务分配到多个系统或链路。

## 2. 网络分类

| 分类维度 | 类型                         | 说明                       |
| -------- | ---------------------------- | -------------------------- |
| 覆盖范围 | PAN、LAN、MAN、WAN           | 从个人区域到广域互联       |
| 传输技术 | 广播式、点对点式             | 共享信道或通过链路逐跳转发 |
| 拓扑结构 | 总线、星形、环形、网状       | 描述节点和链路连接关系     |
| 使用者   | 公用网、专用网               | 面向公众或特定组织         |
| 交换方式 | 电路交换、报文交换、分组交换 | 建立专用通路或采用存储转发 |

分组交换将报文拆分为分组，逐跳存储转发，链路可被多个通信共享；代价是可能产生排队、丢包和时延抖动。

## 3. 性能指标

### 3.1 速率、带宽与时延

- 速率：单位时间传输的数据量，常用 bit/s。
- 带宽：在不同语境下可表示频率范围或最大数据传输能力，需结合题目定义。
- 发送时延：把分组全部比特推送到链路所需时间。
- 传播时延：信号在链路介质中传播所需时间。
- 处理时延：节点检查分组、查表等处理时间。
- 排队时延：分组在队列中等待发送的时间。

发送时延：

$$
d_{trans}=\frac{L}{R}
$$

其中 $L$ 为分组长度（bit），$R$ 为链路发送速率（bit/s）。

传播时延：

$$
d_{prop}=\frac{D}{V}
$$

其中 $D$ 为链路长度（m），$V$ 为信号传播速度（m/s）。

节点总时延通常由处理、排队、发送和传播时延组成：

$$
d_{total}=d_{proc}+d_{queue}+d_{trans}+d_{prop}
$$

### 3.2 时延带宽积

$$
BDP=R\times d_{prop}
$$

时延带宽积表示链路上可同时“在途”的比特数量。它有助于理解长肥网络中为什么需要较大的窗口才能充分利用链路。

### 3.3 丢包率与利用率

- 丢包率：丢失分组数占发送分组数的比例（具体统计口径依题目）。
- 利用率：链路或设备忙于传输的时间/能力占比。
- 吞吐量：实际单位时间成功传输的数据量，受瓶颈链路、协议开销、拥塞和接收能力等因素影响。

## 4. 网络协议与分层

### 4.1 协议三要素

1. 语法：数据与控制信息的格式、字段和编码。
2. 语义：字段含义及需要完成的操作。
3. 同步（时序）：事件发生顺序、速率匹配和状态转换规则。

协议规定通信双方如何交换信息；接口描述相邻层之间如何交互；服务描述下层向上层提供什么能力。

### 4.2 为什么分层

- 将复杂通信任务拆分为相对独立的功能模块。
- 降低系统设计与实现复杂度。
- 便于不同厂商设备按统一标准互联。
- 某一层内部实现变化时，只要服务接口保持兼容，上下层通常不必全部改变。

分层并非没有代价：协议头增加开销，跨层优化受限，某些功能可能在不同层重复出现。

## 5. OSI 与 TCP/IP 体系结构

| OSI 七层   | TCP/IP 常见四层 | 主要职责/示例              |
| ---------- | --------------- | -------------------------- |
| 应用层     | 应用层          | HTTP、DNS、FTP、SMTP       |
| 表示层     | 应用层          | 数据表示、编码、加密等功能 |
| 会话层     | 应用层          | 会话建立、管理与同步       |
| 传输层     | 传输层          | TCP、UDP，端到端进程通信   |
| 网络层     | 网际层          | IP 寻址、路由与转发        |
| 数据链路层 | 网络接口层      | 成帧、MAC、差错检测        |
| 物理层     | 网络接口层      | 比特传输、信号与介质       |

TCP/IP 也常按五层教学模型拆分为应用层、运输层、网络层、数据链路层和物理层。答题时要明确采用四层还是五层口径。

## 6. 封装与解封装

发送端数据逐层向下传递，每层添加本层控制信息（首部，某些层还添加尾部），形成协议数据单元（PDU）；接收端逐层向上处理并移除相应控制信息。

| 层次       | 常见 PDU 名称           |
| ---------- | ----------------------- |
| 应用层     | 报文/消息               |
| 传输层     | TCP 段 / UDP 用户数据报 |
| 网络层     | IP 数据报（分组）       |
| 数据链路层 | 帧                      |
| 物理层     | 比特                    |

同一层的对等实体在逻辑上按协议通信；实际数据仍由本机逐层交付给下层，再经物理链路传输。

## 7. 例题与计算

**例 1：发送时延**

一个 1500 Byte 的分组通过 10 Mbit/s 链路发送，忽略其他开销，求发送时延。

$$
L=1500\times8=12000\ bit
$$

$$
d_{trans}=\frac{12000}{10\times10^6}=1.2\ ms
$$

**例 2：传播时延**

链路长度 2000 km，信号传播速度 $2\times10^8$ m/s：

$$
d_{prop}=\frac{2\times10^6}{2\times10^8}=0.01\ s=10\ ms
$$

**例 3：时延组成辨析**

提高链路发送速率会缩短发送时延，但在链路长度和介质不变时，不会直接缩短传播时延。

## 8. 高频易错点

1. 发送时延由分组长度和链路速率决定；传播时延由距离和传播速度决定。
2. 带宽、速率、吞吐量不是完全相同的概念。
3. 时延带宽积的单位是 bit，不是 bit/s。
4. 协议三要素是语法、语义、同步（时序）。
5. 服务是下层向上层提供的功能，协议是对等层实体交换信息的规则。
6. OSI 七层与 TCP/IP 四层/五层映射不是逐字一一对应。
7. 数据链路层的帧与网络层的数据报不可混称。

## 10. 本章五大经典学习法｜计算机网络体系结构

### 10.1 费曼学习法：解释数据如何从一台主机到达另一台主机

计算机网络把自治主机通过通信链路和交换设备连接起来。应用产生的数据经过各层协议逐层封装，形成适合当前网络传输的协议数据单元；接收端再逐层解封装，交给目标应用。

- **网络边缘**：端系统和应用，负责产生/消费数据。
- **网络核心**：交换设备和链路，负责转发数据。
- **分组交换**：把报文拆成分组，链路资源可被多个通信共享，但可能有排队、丢包和时延抖动。
- **协议**：规定通信双方交换什么、何时交换、如何解释；常概括为语法、语义和同步/时序。
- **服务**：下层向上层提供的功能；协议是实现通信规则的约定。
- **封装/解封装**：发送端逐层添加首部（必要时尾部），接收端逐层解析并移除。

**费曼复述练习：**

1. 用寄快递类比解释分组交换和逐跳转发。
2. 为什么协议与服务不是同一个概念？
3. 为什么发送端要逐层封装，接收端要逐层解封装？
4. 发送时延、传播时延、处理时延和排队时延分别由什么决定？
5. 为什么带宽高不代表端到端时延一定低？

**边界提醒：** 发送时延由分组长度和链路速率决定；传播时延由链路距离和传播速度决定。吞吐率、带宽、时延、时延带宽积是不同指标，不可互换。

### 10.2 西蒙学习法：拆成网络基础五个模块

| 模块 | 内容 | 前置关系 | 达标练习 |

| C. 性能指标 | 速率、带宽、时延、吞吐率、时延带宽积 | A、B | 完成发送/传播/总时延计算 |

### 10.5 康奈尔笔记法：网络体系结构线索卡

| 左侧线索 / 问题 | 右侧主体笔记 |
|---|---|
| 网络组成？ | 主机、通信链路、交换设备和网络协议。 |
| 网络边缘/核心？ | 边缘负责应用和信息处理；核心负责数据交换与转发。 |
| 分组交换？ | 报文分组后逐跳存储转发，资源共享率高，但可能排队、丢包和抖动。 |
| 发送时延？ | L/R，L 为分组比特数，R 为链路速率。 |
| 传播时延？ | d/v，d 为链路距离，v 为信号传播速度。 |
| 排队时延？ | 取决于网络负载和排队情况，具有变化性。 |
| 处理时延？ | 结点检查首部、差错检测和路由查找等处理所需时间。 |
| 协议三要素？ | 语法（格式）、语义（含义/动作）、时序（顺序与同步）。 |
| 服务与协议？ | 服务描述层间提供什么功能；协议规定对等实体如何通信。 |
| 封装/解封装？ | 发送端逐层添加控制信息；接收端逐层解析移除。 |

**页底总结：** 网络基础章节要建立“主机—链路—交换设备—协议分层”的整体模型。计算题按时延类型拆分；概念题区分协议、服务和接口；封装题按发送/接收方向逐层分析。

### 10.6 五法融合自测

1. 分组长度 12000 bit，链路速率 6 Mbit/s，发送时延是多少？
2. 链路距离 1500 km，传播速度 2×10⁸ m/s，传播时延是多少？
3. 为什么发送时延与距离无关，而传播时延与分组长度无关？
4. 协议的语法、语义、时序分别规定什么？
5. 服务与协议的区别是什么？
6. 分组交换相较电路交换的主要优点和代价是什么？
7. 为什么 OSI 七层与 TCP/IP 层次不应机械一一对应？

**答案要点：** 1. 12000/(6×10⁶)=2 ms；2. 1.5×10⁶/(2×10⁸)=7.5 ms；3. 发送时延由数据量/链路速率决定，传播时延由距离/传播速度决定；4. 格式、含义/动作、顺序/同步；5. 服务是层间功能，协议是对等实体通信规则；6. 资源共享和统计复用更灵活，但可能排队和丢包；7. 两套体系结构的分层目标和边界不同，TCP/IP 将部分 OSI 层合并。
