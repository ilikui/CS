# 计算机网络｜五大经典学习法应用指南

> 本指南把五大经典学习法落实到本学科各章节。每个章节中的每个概念问题，均回到[408 概念学习标准](../五大经典学习法-408统一模板.md)，按五个独立环节完成。

## 第01章 计算机网络体系结构

**本章概念群：** 网络组成、交换方式、性能指标、协议/服务/接口、分层、封装。

**五法应用：** 用邮政系统讲分层；拆协议三要素、层间服务、PDU 和封装；SQ3R 追问协议/服务/接口区别；番茄画端到端封装；康奈尔记录层次、PDU 与时延公式。

| 学习法 | 本章必须产出的学习成果 |
|---|---|
| 费曼学习法 | 能用自己的话讲清核心概念、工作原理、适用边界和一个反例 |
| 西蒙学习法 | 把概念拆成定义、条件、步骤、性质/复杂度等知识块，并标明先修关系 |
| SQ3R 阅读法 | 完成浏览、提问、精读、闭卷复述、间隔复习五步 |
| 番茄工作法 | 至少一个 25 分钟专注任务，留下可检查的练习结果 |
| 康奈尔笔记法 | 留下线索问题、核心笔记、页底总结和错因 |

## 第03章 数据链路层
