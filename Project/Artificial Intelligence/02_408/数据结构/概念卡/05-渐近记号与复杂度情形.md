# 渐近记号 O、Ω、Θ 与复杂度情形

> 408 数据结构 · 第 01 章原子化概念卡。建议先独立完成自测，再查看解析。

## 一句话定义

O、Ω、Θ 是描述函数渐近增长关系的数学记号；最好、最坏、平均情况则是针对不同输入情形的算法分析方式。两组概念不能混为一谈。

## 三种渐近记号

设 f(n)、g(n) 为非负函数：
- f(n)=O(g(n))：存在 c>0、n₀，使 n≥n₀ 时 f(n)≤c·g(n)，表示渐近上界。
- f(n)=Ω(g(n))：存在 c>0、n₀，使 n≥n₀ 时 f(n)≥c·g(n)，表示渐近下界。
- f(n)=Θ(g(n))：同时满足 O 与 Ω，表示同阶。

例：
$$f(n)=3n^2+5n+7=\Theta(n^2)$$

## 三种分析情形

以长度 n 的顺序查找为例：
- 最好情况：目标位于第一个位置，比较 1 次。
- 最坏情况：目标位于最后一个位置或不存在，比较 n 次。
- 平均情况：必须明确输入概率分布。若目标等概率出现在每个位置且必定存在，平均比较次数为 (n+1)/2。

若把查找失败纳入平均情况，需要明确失败概率与失败时比较次数。

## 费曼学习法

把最好/最坏/平均情况想成不同输入带来的任务量；把 O/Ω/Θ 想成对任务量增长趋势的数学边界描述。一个回答“选择什么输入情形”，另一个回答“函数增长关系如何”。

**复述练习：** 解释“最坏时间复杂度是 O(n²)”这句话里，最坏情况与 O 分别是什么意思。

**边界提醒：** Big-O 常用于表达最坏情况的上界，但 Big-O 本身不等于最坏情况；任何情形的复杂度函数都可以用 O 记号描述上界。

## 西蒙学习法

1. 先练函数比较：忽略低阶项与常数因子。
2. 再练记号定义：上界、下界、同阶。
3. 再练输入情形：最好、最坏、平均。
4. 最后把两者组合：例如“最坏情况下为 O(n²)”。
5. 平均情况题必须显式写概率模型。

## SQ3R 阅读法

- Survey：浏览三个记号定义与顺序查找例子。
- Question：O 是否一定是最坏情况？平均复杂度为什么需要概率分布？
- Read：逐字核对不等式定义和概率假设。
- Recite：不看资料写出 O/Ω/Θ 的定义，并推导顺序查找 ASL。
- Review：用不同多项式和查找场景重复练习。

## 康奈尔笔记

| 线索问题 | 主体笔记 |
|---|---|
| O？ | 渐近上界 |
| Ω？ | 渐近下界 |
| Θ？ | 渐近同阶，上下界同时成立 |
| 最好情况？ | 在规定输入规模下，最有利输入的代价 |
| 最坏情况？ | 最不利输入的代价 |
| 平均情况？ | 按明确概率分布计算期望代价 |

**页底总结：** 先说明分析情形，再使用渐近记号描述增长界。平均情况不是“随便取中间值”，而是概率加权的期望。

## 自测与解析

1. 4n³+2n²+1 的 Θ 阶？——Θ(n³)。
2. Ω 表示什么？——渐近下界。
3. 最坏情况和 Big-O 是否同义？——不是。
4. 等概率成功顺序查找的 ASL？——(n+1)/2。
5. 平均复杂度计算必须给出什么？——输入概率分布/概率模型。
