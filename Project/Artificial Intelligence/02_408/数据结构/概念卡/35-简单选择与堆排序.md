# 35｜简单选择排序与堆排序

## 简单选择排序
每趟从未排序区间选出最小元素，与区间首元素交换，逐步扩大有序前缀。
- 比较次数通常 Θ(n²)，辅助空间 O(1)。
- 通常不稳定：最小值与首元素远距离交换可能跨越相同关键字记录。

## 堆排序
利用堆顶是当前最大值（大根堆）或最小值（小根堆）的性质：
1. 自底向上建堆；
2. 交换堆顶与末尾元素；
3. 缩小堆范围；
4. 对新堆顶向下调整，重复直到完成。
- 建堆 O(n)；完整排序 O(n log n)。
- 原地实现辅助空间 O(1)，通常不稳定。

## 例题
数组 [4,1,3,2] 建成大根堆后，堆顶为最大值 4；交换到末尾并缩小堆，再对根进行向下调整。手算时每次都要区分“有效堆区间”和“已排序后缀”。

## 五法学习
1. **费曼**：选择排序每次直接挑最小；堆排序把“当前最大”放在堆顶，像随时维护一个冠军。
2. **西蒙**：拆为选择区间、堆序性质、建堆、交换堆顶、向下调整、复杂度。
3. **SQ3R**：浏览堆图；提问“为何建堆 O(n) 而非 O(n log n)”；精读自底向上调整；遮住笔记画堆；隔日重做。
4. **番茄**：25 分钟手算两组选择排序、两组建堆与排序，休息 5 分钟复盘下滤路径。
5. **康奈尔**：左栏写“建堆/筛选/堆区间/稳定性”，右栏记录数组与树形状态，页底总结建堆和排序阶段复杂度不同。

## 易错边界
- 自底向上建堆为 O(n)，不能误写成 O(n log n)。
- 排序阶段每次取出堆顶后都要缩小有效堆范围。
- 大根堆通常得到升序结果（堆顶最大值依次放到数组末尾）。
- 堆排序不稳定；选择排序通常也不稳定。

## 自测
1. 自底向上建堆的时间复杂度？
2. 堆排序完整时间复杂度？
3. 简单选择排序为何不稳定？

**答案**：1. O(n)；2. O(n log n)；3. 远距离交换可能改变相同关键字记录的相对次序。

## C 语言实现与堆状态跟踪

### 简单选择排序

```c
void selection_sort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        int min_idx = i;
        for (int j = i + 1; j < n; ++j) {
            if (a[j] < a[min_idx]) min_idx = j;
        }
        if (min_idx != i) {
            int t = a[i]; a[i] = a[min_idx]; a[min_idx] = t;
        }
    }
}
```

每趟扫描未排序区间，记录最小值下标，最后至多交换一次。比较次数为 `n(n-1)/2`，与输入初始有序程度基本无关。

### 大根堆：自底向上建堆与堆排序

以下采用从下标 0 开始的数组表示，结点 i 的左、右孩子分别为 `2*i+1`、`2*i+2`。

```c
void sift_down(int a[], int root, int size) {
    while (2 * root + 1 < size) {
        int child = 2 * root + 1;
        if (child + 1 < size && a[child + 1] > a[child]) ++child;
        if (a[root] >= a[child]) break;
        int t = a[root]; a[root] = a[child]; a[child] = t;
        root = child;
    }
}

void heap_sort(int a[], int n) {
    for (int i = n / 2 - 1; i >= 0; --i)
        sift_down(a, i, n);              /* O(n) 建堆 */
    for (int end = n - 1; end > 0; --end) {
        int t = a[0]; a[0] = a[end]; a[end] = t;
        sift_down(a, 0, end);            /* 仅调整有效堆区间 */
    }
}
```

### 手算跟踪

对 `[4, 1, 3, 2]` 自底向上建大根堆：

| 阶段 | 数组 | 解释 |
|---|---|---|
| 初始 | 4, 1, 3, 2 | 从最后一个非叶结点 i=1 开始 |
| 调整 i=1 | 4, 2, 3, 1 | 结点 1 与较大孩子 2 交换 |
| 调整 i=0 | 4, 2, 3, 1 | 根 4 已不小于孩子，无需交换 |

得到大根堆后，每次将堆顶最大值放到数组末尾，堆有效长度减 1，再对根下滤。注意“已排序后缀”不再属于堆。

**复杂度解释**：建堆为 O(n)，因为大量结点高度很低；排序阶段最多 n-1 次下滤，每次 O(log n)，总计 O(n log n)。

**边界测试**：空数组、单元素数组；含重复值；负数；堆大小缩小到 1。所有比较均适用于一般有符号 int。

### 真题变式

若题目要求升序排序，使用大根堆并将堆顶依次交换到末尾；若要求降序，可使用小根堆。不要把“堆顶最大”误写成最终升序数组的首元素——堆排序过程中最大值被放到末尾。

### 五法强化任务

- **SQ3R**：先画完全二叉树，再读 sift_down，最后遮住代码独立写出。
- **番茄**：25 分钟完成一组建堆和两轮堆顶交换，休息 5 分钟。
