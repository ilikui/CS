# 概念卡 16｜特殊矩阵压缩存储：对称、三角与稀疏矩阵

## 核心定义
压缩存储利用矩阵的结构规律，只保存必要元素，并建立二维坐标到一维数组下标的映射。

### 对称矩阵
满足 a[i][j]=a[j][i]。若下三角（含主对角线）按行优先、0 起始存储：
- 当 i≥j：k=i(i+1)/2+j
- 当 i<j：先交换 i、j，再套用下三角公式。
存储元素数为 n(n+1)/2。

### 三角矩阵
上/下三角矩阵的非零区域不同，压缩映射公式取决于：上三角还是下三角、是否包含主对角线、按行还是列优先、下标起点。先画出存储顺序，再推导，不能把对称矩阵公式直接照搬。

### 稀疏矩阵
- 三元组表：每个非零元素记录 (行号, 列号, 数值)，结构简单、节省空间；按行列查找可能需要扫描。
- 十字链表：非零结点同时链接同一行和同一列，便于按行/列遍历与修改；指针维护更复杂。

## 五大经典学习法
### 1. 费曼学习法
解释压缩存储像只记录棋盘上有棋子的格子。对称矩阵只保存一侧，因为另一侧可由对称关系恢复；稀疏矩阵只保存非零项，因为零值占绝大多数。

### 2. 西蒙学习法
①识别矩阵性质；②确定保留区域；③确定遍历次序；④推导坐标映射；⑤比较存储结构。按这个顺序做题，每次只改变一个条件观察公式如何变化。

### 3. SQ3R 阅读法
- Survey：浏览矩阵形状图和一维映射示意。
- Question：为什么要先判断 i、j？三元组表与十字链表的操作差别是什么？
- Read：按行列顺序逐格编号，自己推导 k。
- Recite：不看公式推导 a[3][1] 的映射下标。
- Review：当天画出三类矩阵，次日默写公式，第 3/7 天做边界下标题。

### 4. 番茄工作法
番茄 1（25 分钟）：对称矩阵映射 4 题；番茄 2（25 分钟）：三角矩阵推导与稀疏矩阵比较；每轮休息 5 分钟。验收：能说明公式适用前提。

### 5. 康奈尔笔记法
| 线索 | 笔记 |
|---|---|
| 对称矩阵 | aij=aji，只存一侧即可 |
| 下三角行优先 | k=i(i+1)/2+j（i≥j，0 起始） |
| 上三角映射 | 依据具体存储顺序单独推导 |
| 三元组表 | 行、列、值 |
| 十字链表 | 同时维护行链和列链 |
| 压缩核心 | 先识别结构，再建立坐标映射 |

**总结：** 压缩存储的关键是明确“存什么、按什么顺序、坐标如何映射”，每个公式都必须附带前提条件。

## 自测与答案
1. 对称矩阵压缩存储的依据？**答：aij=aji，只保存主对角线一侧。**
2. n=5 时下三角（含主对角线）需存多少元素？**答：5×6/2=15。**
3. 0 起始下三角按行优先，a[3][1] 的 k？**答：3×4/2+1=7。**
4. 三元组表保存哪三个字段？**答：行号、列号、数值。**
5. 十字链表比三元组表更便于什么操作？**答：按行和按列遍历/修改非零元素。**

**达标标准：** 能根据条件推导映射式；能区分对称/三角/稀疏矩阵；能比较三元组表与十字链表。
