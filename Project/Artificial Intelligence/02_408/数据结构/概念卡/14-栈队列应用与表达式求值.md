# 概念卡 14｜栈与队列的应用：匹配、表达式、递归与 BFS

## 核心知识
### 括号匹配
从左向右扫描：左括号入栈；遇到右括号，若栈空则失败，否则弹出并检查类型；扫描结束后栈必须为空。时间 O(n)，辅助空间最坏 O(n)。

### 中缀转后缀与表达式求值
操作数直接输出；左括号入栈；右括号弹出至对应左括号；运算符依据优先级和结合性决定是否弹栈。后缀表达式求值时，操作数入栈，遇到二元运算符弹出右操作数和左操作数，计算后再入栈。注意减法、除法的弹栈顺序，以及一元负号和乘方结合性。

### 递归与调用栈
递归调用需要保存返回地址、局部变量和现场信息。深度为 d 时，调用栈空间通常为 O(d)。递归终止条件不完整可能导致无限递归或栈溢出。

### BFS 与队列
BFS 从起点开始，将已发现但尚未扩展的顶点入队；每次取队头扩展邻接点。用于无权图最短路径时，按层次首次到达即可得到边数最少路径。访问标记通常在入队时设置，避免重复入队。

## 五大经典学习法
### 1. 费曼学习法
解释“最近遇到的左括号最先匹配”为什么是 LIFO；解释 BFS 为什么让先发现的顶点先扩展；用一次函数调用说明调用栈保存了什么。

### 2. 西蒙学习法
拆分为四块：括号匹配、运算符处理、递归调用栈、BFS。先掌握栈/队列基本操作，再做应用模拟；表达式题按“扫描符号—栈状态—输出/计算”三列记录。

### 3. SQ3R 阅读法
- Survey：浏览四种应用的流程图和伪代码。
- Question：为什么结束时检查栈空？后缀求值时左右操作数顺序为何重要？
- Read：逐字符模拟括号匹配和中缀转换，逐顶点模拟 BFS。
- Recite：闭卷写出括号匹配与 BFS 框架。
- Review：当天重做表达式，次日手算 BFS，第 3/7 天复盘递归边界。

### 4. 番茄工作法
番茄 1（25 分钟）：括号匹配 3 题；番茄 2（25 分钟）：中缀转后缀与后缀求值；番茄 3（25 分钟）：递归调用栈和 BFS；每轮休息 5 分钟。验收时写出每一步栈/队列内容。

### 5. 康奈尔笔记法
| 线索 | 笔记 |
|---|---|
| 括号匹配 | 左括号入栈，右括号匹配弹栈，结束检查空栈 |
| 后缀求值 | 先弹右操作数，再弹左操作数 |
| 递归栈 | 保存返回地址、局部变量、现场 |
| BFS | FIFO 队列实现层次扩展 |
| 标记时机 | BFS 常在入队时标记，避免重复入队 |

**总结：** 栈处理“最近的待完成事项”；队列处理“先发现先处理的任务”。应用题的关键是明确状态保存顺序。

## 自测与答案
1. ([{}]) 是否匹配？**答：匹配。**
2. ([)] 是否匹配？**答：不匹配，最近的左括号类型不符。**
3. 后缀表达式 8 2 - 的结果？**答：6，先弹 2 为右操作数，再弹 8 为左操作数。**
4. BFS 为什么常在入队时标记？**答：防止同一顶点被多个邻接点重复入队。**
5. 递归深度 d 的调用栈空间通常是多少阶？**答：O(d)。**

**达标标准：** 能手算括号匹配、表达式转换/求值；能解释递归调用栈；能写出 BFS 队列框架。
