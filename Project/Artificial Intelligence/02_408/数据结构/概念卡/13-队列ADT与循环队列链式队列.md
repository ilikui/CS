# 概念卡 13｜队列 ADT、循环队列与链式队列

## 核心定义
队列是只允许在队尾插入、队头删除的线性表，遵循先进先出（FIFO）。核心操作为 InitQueue、EnQueue、DeQueue、GetHead、QueueEmpty。

### 循环队列（牺牲一个单元）
设数组长度为 m，front 指向队头元素，rear 指向下一次入队位置：
- 队空：front==rear
- 队满：(rear+1)%m==front
- 入队：写 data[rear]，再令 rear=(rear+1)%m
- 出队：读取 data[front]，再令 front=(front+1)%m
- 元素个数：(rear-front+m)%m
- 最大可用容量：m-1

### 链式队列
使用 front、rear 指针。入队在尾部插入，出队在头部删除；若维护尾指针，二者均可 O(1)。删除最后一个结点后，必须将 rear 恢复为空队列状态，避免悬空指针。

## 五大经典学习法
### 1. 费曼学习法
把队列解释为排队：先到先服务。循环队列像环形跑道，指针到数组末尾后回到 0。说明“牺牲一个单元”是为了让空与满的状态可区分。

### 2. 西蒙学习法
①FIFO 与操作端点；②循环队列的状态变量和取模；③链式队列的首尾指针维护。先手算指针，再写代码，最后覆盖队空、队满、删除最后元素的边界。

### 3. SQ3R 阅读法
- Survey：先看队列操作图与循环队列状态图。
- Question：为什么 front==rear 不能同时表示满？容量为何少 1？
- Read：对每次入队/出队记录 front、rear 和元素数。
- Recite：不看资料推导判满式与长度公式。
- Review：当天做状态追踪，次日默写公式，第 3/7 天做综合题。

### 4. 番茄工作法
番茄 1：25 分钟完成 5 组循环队列指针追踪；番茄 2：25 分钟写链式队列入队、出队并测试删除最后结点；每轮休息 5 分钟。

### 5. 康奈尔笔记法
| 线索 | 笔记 |
|---|---|
| FIFO | 队尾入队、队头出队 |
| 循环队列判空 | front==rear |
| 循环队列判满 | (rear+1)%m==front |
| 有效容量 | m-1 |
| 当前长度 | (rear-front+m)%m |
| 链队列边界 | 删除最后结点时同步更新 rear |

**总结：** 循环队列用取模复用数组空间；链式队列用指针连接结点。公式必须与指针定义保持一致。

## 自测与答案
1. m=8 的循环队列最多存几个元素？**答：7。**
2. front=6、rear=2、m=10，当前元素数？**答：(2-6+10)%10=6。**
3. 判满条件是什么？**答：(rear+1)%m==front。**
4. 链式队列删除唯一结点后要更新什么？**答：front 与 rear 都恢复空队列约定状态。**

**达标标准：** 能独立手算循环队列状态；能解释 m-1 容量；能正确处理链式队列空队列边界。
