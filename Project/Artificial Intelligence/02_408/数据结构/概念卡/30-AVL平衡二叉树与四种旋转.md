# 30｜AVL 平衡二叉树与四种旋转

## 一句话定义
AVL 树是满足任意结点左右子树高度差绝对值不超过 1 的 BST，通过旋转维持高度平衡。

## 平衡因子
常见定义 BF=左子树高度−右子树高度（也有教材采用相反符号，必须先确认）。AVL 要求每个结点 |BF|≤1。

## 四种失衡与调整
- **LL**：在失衡结点左孩子的左子树插入，右旋。
- **RR**：在右孩子的右子树插入，左旋。
- **LR**：在左孩子的右子树插入，先对左孩子左旋，再对失衡结点右旋。
- **RL**：在右孩子的左子树插入，先对右孩子右旋，再对失衡结点左旋。

## 复杂度
AVL 高度为 O(log n)，查找、插入、删除为 O(log n)。旋转只改变局部指针关系，必须保持 BST 的中序次序。删除可能使多个祖先结点依次失衡，需要向上继续检查。

## 例题
插入 30、20、10：结点 30 左左失衡，执行右旋，得到根 20，左右孩子分别为 10、30。

## 五法学习
1. **费曼**：AVL 像不断调整支架，避免树向一侧倒下；旋转是局部重排，不改变关键字的中序顺序。
2. **西蒙**：拆为高度/BF 定义、失衡位置、四类模式、旋转次序、复杂度。
3. **SQ3R**：先看四种失衡图；提问“新结点插入在哪条路径”；精读旋转指针；合上资料复画；隔日混合判断。
4. **番茄**：25 分钟各做一例 LL、RR、LR、RL，休息 5 分钟后不看答案再做一轮。
5. **康奈尔**：左栏写“LL/RR/LR/RL”，右栏写插入路径和旋转顺序，页底总结“外侧单旋、内侧双旋”。

## 易错边界
- 先统一 BF 正负号约定。
- LL/RR 是单旋；LR/RL 是双旋。
- 旋转后必须检查中序序列是否保持不变。
- AVL 的平衡条件是每个结点都满足，不是只检查根结点。

## 自测
1. 插入 30、20、10 属于哪类失衡，如何调整？
2. LR 失衡需要几次基本旋转？
3. AVL 查找最坏时间复杂度是多少？

**答案**：1. LL，右旋；2. 两次，先左旋左孩子，再右旋失衡结点；3. O(log n)。

## C 语言核心操作：高度更新与旋转

约定空树高度为 0、叶结点高度为 1，平衡因子 `BF=height(left)-height(right)`。

```c
#include <stdlib.h>
typedef struct AVLNode {
    int key, height;
    struct AVLNode *left, *right;
} AVLNode;

static int h(AVLNode *p) { return p ? p->height : 0; }
static int max2(int a, int b) { return a > b ? a : b; }
static void update(AVLNode *p) {
    p->height = 1 + max2(h(p->left), h(p->right));
}

static AVLNode *rotate_right(AVLNode *y) {
    AVLNode *x = y->left, *t = x->right;
    x->right = y; y->left = t;
    update(y); update(x);
    return x;
}
static AVLNode *rotate_left(AVLNode *x) {
    AVLNode *y = x->right, *t = y->left;
    y->left = x; x->right = t;
    update(x); update(y);
    return y;
}
```

旋转只负责局部结构调整；插入/删除后还要从受影响结点向上更新高度、计算 BF 并选择 LL/RR/LR/RL。单旋后更新高度的顺序应先更新下沉结点，再更新新的子树根。

| 类型 | 失衡特征 | 调整 |
|---|---|---|
| LL | 左孩子的左子树更高 | 对失衡结点右旋 |
| RR | 右孩子的右子树更高 | 对失衡结点左旋 |
| LR | 左孩子的右子树更高 | 先左旋左孩子，再右旋失衡结点 |
| RL | 右孩子的左子树更高 | 先右旋右孩子，再左旋失衡结点 |

### 旋转前后校验

LL 插入序列 `30,20,10`：旋转前局部中序为 `10,20,30`，右旋后仍为 `10,20,30`。旋转改变形态，不改变 BST 中序次序。

**边界提醒**：BF 正负号取决于教材约定；本卡固定使用左高减右高。删除操作可能让多个祖先结点连续失衡，不能照搬“插入只需修复首个失衡点”的简化结论。
