# 单链表指针操作与内存管理

> 408 数据结构 · 第 02 章原子化概念卡。五法学习 + 独立自测。

## 核心定义

单链表由结点组成，每个结点包含数据域 data 和指向后继的 next 指针。结点在内存中不要求连续，逻辑顺序由 next 链接确定。

## 核心操作

**带头结点的空表：** head->next == NULL。

**按位序查找：** 从头结点开始沿 next 前进，访问第 i 个数据结点需要 O(n)。

**在已知结点 p 后插入 s：**
```c
s->next = p->next;
p->next = s;
```
先保存原后继关系，再把 p 指向 s。

**删除 p 的后继 q：**
```c
q = p->next;
p->next = q->next;
free(q);
```
先保存待删除结点，再调整链接，最后释放空间。

**重要复杂度前提：** 已知前驱时链接修改为 O(1)；若需要先按位序寻找前驱，总时间为 O(n)。

## 五法学习

### 费曼学习法
把链表想成一串寻路卡片，每张卡片只记下一张卡片的位置。插入时先让新卡片指向原下一张，再让前一张指向新卡片；顺序不能反，否则可能丢失后半段链表。

复述：为什么插入要先执行 s->next=p->next？为什么删除前要保存 q？

### 西蒙学习法
拆为结点结构、遍历定位、插入链接、删除释放四个模块。先画指针图，再写两行链接修改，最后加入 NULL 检查和 free。练习覆盖空表、首元、尾结点和只有一个结点的链表。

### 康奈尔笔记
| 线索 | 笔记 |
|---|---|
| 结点组成？ | 数据域 data + 指针域 next |
| 头结点？ | 辅助结点，不存放线性表数据 |
| 首元结点？ | 第一个实际数据结点 |
| 插入顺序？ | s->next=p->next，再 p->next=s |
| 删除顺序？ | 保存 q，调整 p->next，再 free(q) |
| 按位序查找？ | O(n) |
| 已知前驱插入？ | 链接修改 O(1)，定位成本另算 |

页底总结：链表算法的核心是保护原链接、避免丢链、正确释放结点。O(1) 仅指已定位后的局部链接修改。

## 自测
1. 带头结点空表条件？——head->next==NULL。
2. 先修改 p->next=s 再写 s->next=p->next 会怎样？——s 可能指向自身，原后继丢失。
3. 已知前驱插入复杂度？——O(1)。
4. 按位序找到前驱再插入总复杂度？——O(n)。
5. 删除结点后为何 free？——释放动态分配的内存，避免内存泄漏。
