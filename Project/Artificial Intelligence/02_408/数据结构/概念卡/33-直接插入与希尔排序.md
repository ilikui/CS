# 33｜直接插入排序与希尔排序

## 一句话定义
插入类排序维护一个逐步扩大的有序子序列；直接插入逐个插入，希尔排序先按增量分组进行预排序。

## 直接插入排序
将第 i 个元素暂存为 key，在已排序前缀中从后向前比较并移动大于 key 的元素，最后将 key 放入空位。
- 最好时间 O(n)：输入已有序。
- 平均/最坏 O(n²)；辅助空间 O(1)。
- 稳定：相等元素不跨越彼此（实现中只移动严格大于 key 的元素）。

## 希尔排序
选取递减增量序列，对相距 gap 的元素进行分组插入排序；最终 gap=1 完成整体排序。
- 通过预排序减少最后一趟插入的移动量。
- 通常不稳定；复杂度依赖增量序列，不能脱离增量方案写固定结论。

## 例题
序列 [5,2,4,1] 直接插入：第 1 趟 [2,5,4,1]；第 2 趟 [2,4,5,1]；第 3 趟 [1,2,4,5]。

## 五法学习
1. **费曼**：插入排序像整理扑克牌；希尔排序先把相隔较远的牌大致归位，再做最后精细整理。
2. **西蒙**：拆为有序区/无序区、key 暂存、元素后移、增量分组、稳定性。
3. **SQ3R**：浏览每趟变化；提问“为什么从后向前移动”；精读循环边界；合上资料手算；隔日更换序列。
4. **番茄**：25 分钟完成 3 组插入排序和 2 组希尔排序，休息 5 分钟。
5. **康奈尔**：左栏写“有序区/无序区/key/gap/稳定”，右栏记录过程，页底总结两种算法的核心差异。

## 易错边界
- key 要先保存，否则移动元素可能覆盖待插入值。
- 循环条件应与升序/降序目标一致。
- 希尔排序最终必须执行 gap=1 的一趟。
- 希尔复杂度依赖增量序列，稳定性通常为不稳定。

## 自测
1. 直接插入排序最好情况何时出现？
2. 直接插入排序是否稳定？
3. 希尔排序最后一趟的增量是多少？

**答案**：1. 输入已有序或接近有序；2. 稳定；3. 1。

## C 语言实现与逐趟跟踪

### 直接插入排序

```c
void insertion_sort(int a[], int n) {
    for (int i = 1; i < n; ++i) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = key;
    }
}
```

关键点：先保存 `key`，再整体后移；条件使用 `a[j] > key` 而不是 `>=`，才能保证相等元素不互换，维持稳定性。

### 希尔排序

```c
void shell_sort(int a[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; ++i) {
            int key = a[i];
            int j = i - gap;
            while (j >= 0 && a[j] > key) {
                a[j + gap] = a[j];
                j -= gap;
            }
            a[j + gap] = key;
        }
    }
}
```

这里采用简单的折半增量序列，仅用于演示；希尔排序的时间复杂度取决于增量序列，不能把该实现的经验表现推广为所有增量方案的统一结论。

### 手算跟踪

以 `[5, 2, 4, 1]` 为例，直接插入排序：

| 趟次 | key | 移动后的序列 |
|---|---:|---|
| 初始 | — | 5, 2, 4, 1 |
| 1 | 2 | 2, 5, 4, 1 |
| 2 | 4 | 2, 4, 5, 1 |
| 3 | 1 | 1, 2, 4, 5 |

**边界测试**：空数组和单元素数组无需进入循环；重复值应保持原始相对顺序；降序输入会触发较多移动。

### 真题变式

数组 `[2A, 2B, 1]` 中 A、B 的关键字都为 2。若插入时只移动严格大于 key 的元素，结果为 `[1, 2A, 2B]`，稳定；若错误地使用 `>=`，可能得到 `[1, 2B, 2A]`，破坏稳定性。

- **SQ3R**：先浏览两段代码，再提出“gap 为什么最终必须为 1”，精读循环边界后合上资料复写。
