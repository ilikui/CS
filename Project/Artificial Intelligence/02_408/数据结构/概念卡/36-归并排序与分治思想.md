# 36｜归并排序与分治思想

## 一句话定义
归并排序采用分治：把序列拆成较小子序列，分别排序，再将有序子序列合并。

## 核心步骤
1. 将区间划分为左右两半；
2. 递归排序左右子区间；
3. 双指针比较两侧当前元素，将较小者写入辅助数组；
4. 复制剩余元素并回写。
递归终止条件通常为区间长度不超过 1。

## 复杂度推导
递归式：T(n)=2T(n/2)+O(n)。
每层合并总工作量 O(n)，递归层数 O(log n)，故时间 O(n log n)。
数组实现通常需要 O(n) 辅助空间；稳定合并时相等元素优先取左侧记录，因此稳定。

## 例题
[8,3,6,2] 分成 [8,3] 与 [6,2]；分别排序为 [3,8]、[2,6]；合并得到 [2,3,6,8]。

## 五法学习
1. **费曼**：像整理两摞已排好序的卡片，每次比较两摞最上面一张，取较小者放入新摞。
2. **西蒙**：拆为分解、递归终止、左右有序、双指针合并、回写、复杂度。
3. **SQ3R**：浏览递归树；提问“每层为什么总共 O(n)”；精读合并循环；合上资料手动合并；隔日推导递归式。
4. **番茄**：25 分钟完成两组递归分解图和三组合并过程，休息 5 分钟后推导复杂度。
5. **康奈尔**：左栏写“分治/递归式/合并/空间/稳定”，右栏记录过程，页底总结 O(n log n) 来自 log n 层、每层 O(n)。

## 易错边界
- 递归排序左右区间后仍需执行合并，不能只写分解。
- 合并过程要处理一侧耗尽后的剩余元素。
- 稳定性取决于相等关键字时的取数规则。
- O(n) 辅助空间通常指数组合并缓冲区，不包括输入存储本身。

## 自测
1. 归并排序的递归式是什么？
2. 时间复杂度如何由递归式得到？
3. 数组实现通常需要多少辅助空间？

**答案**：1. T(n)=2T(n/2)+O(n)；2. 每层 O(n)，共 O(log n) 层；3. O(n)。

## C 语言实现与递归跟踪

### 自顶向下归并排序

```c
void merge(int a[], int tmp[], int left, int mid, int right) {
    int i = left, j = mid + 1, k = left;
    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else               tmp[k++] = a[j++];
    }
    while (i <= mid)   tmp[k++] = a[i++];
    while (j <= right) tmp[k++] = a[j++];
    for (int p = left; p <= right; ++p) a[p] = tmp[p];
}

void merge_sort_impl(int a[], int tmp[], int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    merge_sort_impl(a, tmp, left, mid);
    merge_sort_impl(a, tmp, mid + 1, right);
    merge(a, tmp, left, mid, right);
}

/* 调用前分配至少 n 个 int 的 tmp 缓冲区 */
void merge_sort(int a[], int n, int tmp[]) {
    if (n > 1) merge_sort_impl(a, tmp, 0, n - 1);
}
```

相等时优先取左侧元素（`<=`），因此该实现稳定。调用者负责提供长度至少为 n 的辅助数组，避免在递归每层重复分配。

### 合并过程示例

将 `[8, 3, 6, 2]` 分解并排序后得到左段 `[3, 8]`、右段 `[2, 6]`：

| 比较 | 写入辅助数组 | 剩余部分 |
|---|---|---|
| 3 与 2 | 2 | 左 3,8；右 6 |
| 3 与 6 | 2,3 | 左 8；右 6 |
| 8 与 6 | 2,3,6 | 左 8 |
| 左段耗尽后复制 | 2,3,6,8 | 完成 |

递归树每层处理的元素总量为 O(n)，层数为 O(log n)，所以总时间 O(n log n)；辅助数组为 O(n)，递归栈为 O(log n)。

**边界测试**：空数组和单元素数组；奇数长度区间；全部相等；左右区间长度不同；最小值或最大值集中在一侧。

### 真题变式

若把合并条件从 `a[i] <= a[j]` 改为 `a[i] < a[j]`，相等时会优先取右段，可能破坏稳定性。若只复制剩余左段而遗漏剩余右段，也会造成结果缺失。

### 五法强化任务

- **费曼**：用两摞有序扑克牌解释双指针合并。
- **西蒙**：拆为递归终止、左右递归、双指针、复制剩余、回写。
- **SQ3R**：浏览递归树，提问每层为何 O(n)，精读合并循环后复写。
- **番茄**：25 分钟手算两组分解与合并，休息 5 分钟推导递归式。
- **康奈尔**：左栏记 T(n)、mid、双指针和稳定条件，右栏记录合并表。
