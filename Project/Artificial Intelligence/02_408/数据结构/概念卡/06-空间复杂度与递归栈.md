# 空间复杂度、辅助空间与递归栈

> 408 数据结构 · 第 01 章原子化概念卡。建议先独立完成自测，再查看解析。

## 一句话定义

空间复杂度描述算法运行期间所需存储空间随输入规模 n 增长的趋势。分析时要明确是否统计输入本身，并重点关注辅助数组、动态结构和递归调用栈。

## 核心知识

- **固定辅助空间 O(1)**：只使用固定数量变量，与 n 无关。
- **线性辅助空间 O(n)**：创建长度随 n 增长的数组、队列或其他结构。
- **递归栈空间**：取决于递归最大深度以及每层栈帧占用。
- **原地算法**：通常指只使用常数级额外空间（具体以题目约定为准）。

例：
- 迭代求和只用 sum、i 等固定变量：辅助空间 O(1)。
- 复制长度为 n 的数组：辅助空间 O(n)。
- 递归深度为 n、每层常数空间：调用栈 O(n)。
- 二分递归深度 O(log n)，每层常数空间：栈空间 O(log n)。

## 费曼学习法

把递归栈想成一叠尚未完成的待办事项。每深入调用一次，就压入一层记录；返回时再弹出。若最深同时存在 n 层记录，栈空间就随 n 线性增长。

**复述练习：** 比较递归求阶乘与迭代求阶乘的辅助空间，并解释原因。

**边界提醒：** 时间复杂度与空间复杂度是两个不同维度；递归算法即使没有显式数组，也可能因调用栈占用 O(n) 空间。

## 西蒙学习法

把空间分析拆成四步：
1. 明确题目统计口径：是否排除输入空间。
2. 列出显式辅助变量和动态分配对象。
3. 计算递归最大深度。
4. 计算每层栈帧大小，估计总辅助空间。

训练时先做迭代算法，再做递归算法，最后分析含数组和递归的组合算法。

## SQ3R 阅读法

- Survey：浏览 O(1)、O(n)、O(log n) 的空间例子。
- Question：递归为什么占栈？输入数组算不算辅助空间？原地算法是否意味着完全不使用额外空间？
- Read：核对题目统计口径和递归深度。
- Recite：合上笔记，画出递归调用栈并计算最大深度。
- Review：隔天重做递归与数组空间题。

## 康奈尔笔记

| 线索问题 | 主体笔记 |
|---|---|
| 空间复杂度？ | 运行空间需求随输入规模增长的趋势 |
| 辅助空间 O(1)？ | 只使用固定数量额外变量 |
| 辅助数组？ | 长度为 n 时通常 O(n) |
| 递归栈？ | 最大递归深度 × 每层栈帧空间 |
| 原地算法？ | 通常额外空间为常数级，依题目口径判断 |
| 时间/空间权衡？ | 可用额外空间换时间，也可节省空间但增加计算 |

**页底总结：** 空间分析不仅统计显式数组，还要考虑递归栈。先确认统计口径，再列举所有辅助存储并估计随 n 的增长。

## 自测与解析

1. 迭代求和只使用两个变量：辅助空间 O(1)。
2. 复制 n 个元素到新数组：辅助空间 O(n)。
3. 递归深度 n、每层 O(1)：栈空间 O(n)。
4. 二分递归深度 O(log n)、每层 O(1)：栈空间 O(log n)。
5. 递归算法没有显式数组，是否一定 O(1) 空间？——不是，仍需统计调用栈。

**掌握标准：** 能区分输入空间与辅助空间；能计算数组和递归栈空间；能同时给出时间和空间复杂度。
