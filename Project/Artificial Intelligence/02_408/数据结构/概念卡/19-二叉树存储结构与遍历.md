# 19｜二叉树存储结构与遍历

## 存储结构
**顺序存储**：按层序放入数组，完全二叉树空间利用率高；稀疏树会留下大量空位。1 起始编号时，i 的孩子为 2i、2i+1。

**链式存储**：每个结点含 data、lchild、rchild；需要频繁找双亲时可增加 parent 指针。空间随实际结点数增长。

```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

## 四种遍历
- 先序：根—左—右
- 中序：左—根—右
- 后序：左—右—根
- 层序：逐层从左到右，通常使用队列

递归遍历每个结点恰访问一次，时间 (O(n))，递归栈空间 (O(h))，h 为树高；最坏斜树时 h=n。

## 由遍历序列恢复
结点值互异时：
- 先序 + 中序：唯一确定；
- 后序 + 中序：唯一确定；
- 先序 + 后序：一般不唯一，单孩子方向无法确定。

## 例子
树根 A，左子树 B（孩子 D、E），右子树 C：
- 先序：A B D E C
- 中序：D B E A C
- 后序：D E B C A
- 层序：A B C D E

## 五法学习
1. **费曼**：把“访问根的时机”讲清楚；用同一棵树演示四序列。
2. **西蒙**：拆成存储选择、递归模板、四序列、恢复条件；先会单树，再做序列还原。
3. **SQ3R**：浏览代码；提问 visit 在哪一行；精读递归调用；合书默写；隔天手算遍历。
4. **番茄**：25 分钟手算 4 棵树并写递归代码，休息 5 分钟。
5. **康奈尔**：左栏写“遍历顺序/恢复条件/复杂度”，右栏记录示例，页底总结“根何时访问决定序列”。

## 易错边界
- 中序遍历只对二叉树有明确的左根右定义。
- 层序遍历需要队列而不是递归栈。
- 递归空间与树高相关，不总是 O(log n)。
- 恢复唯一性需要结点值唯一等前提。

## 自测
给定先序 A B D E C、中序 D B E A C，写出后序；遍历时间复杂度是多少？

**答案**：D E B C A；(O(n))。
