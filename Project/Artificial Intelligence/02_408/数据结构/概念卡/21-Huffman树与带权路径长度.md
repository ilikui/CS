# 21｜Huffman 树与带权路径长度

## 核心定义
给定 n 个带权叶结点，反复选取当前权值最小的两棵树合并，新结点权值为两者之和，直到只剩一棵树。所得树具有最小带权路径长度。

[
WPL=sum_{i=1}^{n}w_i l_i
]
其中 (w_i) 为叶权值，(l_i) 为叶到根的边数。

## 构造流程
1. 将权值放入最小集合；
2. 取出当前最小的两个权值；
3. 合并为新结点，权值为二者之和；
4. 将新权值放回集合；
5. 重复至仅剩一个根。

标准二叉 Huffman 树无度为 1 的内部结点；n 个叶结点对应 n−1 个内部结点，总结点数 2n−1。

## 例题
权值 2、3、7、9：
- 合并 2+3=5；
- 合并 5+7=12；
- 合并 9+12=21。
叶深度为 3、3、2、1，故 WPL=2×3+3×3+7×2+9×1=38。

## 五法学习
1. **费曼**：把高频权值放在浅层、低频权值放在深层解释为降低总加权路径代价；强调每轮都选当前最小的两项。
2. **西蒙**：拆成贪心选择、合并更新、树结构、WPL 计算；先练 3 个权值，再练 5 个权值。
3. **SQ3R**：先浏览合并过程；提问为何选择最小；精读每轮更新；遮住答案重建；隔天再做不同权值。
4. **番茄**：25 分钟完成两组构造并核对 WPL，休息 5 分钟。
5. **康奈尔**：左栏写“最小两项/WPL/叶深度”，右栏逐轮记录，页底总结“权值乘叶深度再求和”。

## 易错边界
- 每轮选的是当前集合最小两项，不是原始权值排序后固定配对。
- WPL 只对叶结点求和。
- 路径长度通常按边数。
- 左右孩子互换不影响 WPL，但会影响具体编码位串。

## 自测
权值 1、4、6 的 Huffman 树 WPL 是多少？

**答案**：先合并 1+4=5，再合并 5+6=11；WPL=1×2+4×2+6×1=16。
