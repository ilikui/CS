# 29｜二叉排序树 BST：查找、插入与删除

## 一句话定义
BST 是满足左子树关键字小于根、右子树关键字大于根（重复关键字按题目约定处理）的二叉树。

## 核心性质
对任一结点 x：
- 左子树所有关键字小于 x；
- 右子树所有关键字大于 x；
- 左右子树也分别是 BST。
因此，中序遍历可得到递增序列（假设关键字互异）。

## 基本操作
- **查找**：从根开始比较；小于当前结点转左，大于转右，相等命中。
- **插入**：沿查找路径走到空指针处，将新结点接入；不改变已有结点位置。
- **删除**分三类：
  1. 叶结点：直接删除。
  2. 只有一个孩子：用孩子替代被删结点。
  3. 有两个孩子：用中序后继（右子树最小结点）或中序前驱替代，再删除替代结点原位置。

## 复杂度
查找、插入、删除均与树高 h 有关，为 O(h)；平衡时约 O(log n)，退化成单支链时为 O(n)。BST 本身不保证平衡。

## 例题
依次插入 5、3、7、2、4，根为 5；查找 4 的路径为 5→3→4。删除 3 时有两个孩子，可用其中序后继 4 替代，再删除原位置的 4。

## 五法学习
1. **费曼**：把 BST 解释为“每个路口按大小决定左转还是右转”的问答树；中序遍历像从小到大读取。
2. **西蒙**：拆为有序性质、查找路径、插入落点、三类删除、树高复杂度。
3. **SQ3R**：浏览 BST 图；提问“为什么中序有序”；精读删除三种情况；遮住笔记手画；隔日重建不同插入序列。
4. **番茄**：25 分钟构造 2 棵 BST，完成查找、插入及三种删除，休息 5 分钟。
5. **康奈尔**：左栏列“查找/插入/叶删除/单孩子/双孩子”，右栏写指针变化与复杂度，页底总结 O(h) 的原因。

## 易错边界
- BST 不等于平衡二叉树；插入顺序会影响形态。
- 双孩子删除不能直接丢弃某一子树，必须用前驱/后继保持有序性。
- 重复关键字的放置策略必须由题目或实现定义。
- 中序递增结论依赖 BST 的比较规则与重复值约定。

## 自测
1. BST 中序遍历的结果有什么特点？
2. 依次插入 1、2、3、4 会形成什么形态？
3. 删除有两个孩子的结点时，常用哪两个替代结点？

**答案**：1. 关键字递增（互异时严格递增）；2. 右斜单支树；3. 中序前驱或中序后继。

## C 语言实现：BST 查找、插入与删除

以下约定关键字互异；重复关键字策略由具体题目决定。

```c
#include <stdlib.h>
typedef struct Node {
    int key;
    struct Node *left, *right;
} Node;

Node *bst_search(Node *root, int key) {
    while (root && root->key != key)
        root = key < root->key ? root->left : root->right;
    return root;
}

Node *bst_insert(Node *root, int key) {
    if (!root) {
        Node *p = (Node *)malloc(sizeof(*p));
        if (!p) return NULL;
        p->key = key; p->left = p->right = NULL;
        return p;
    }
    if (key < root->key) root->left = bst_insert(root->left, key);
    else if (key > root->key) root->right = bst_insert(root->right, key);
    return root;
}

Node *bst_delete(Node *root, int key) {
    if (!root) return NULL;
    if (key < root->key) root->left = bst_delete(root->left, key);
    else if (key > root->key) root->right = bst_delete(root->right, key);
    else {
        if (!root->left || !root->right) {
            Node *child = root->left ? root->left : root->right;
            free(root);
            return child;
        }
        Node *s = root->right;              /* 中序后继 */
        while (s->left) s = s->left;
        root->key = s->key;
        root->right = bst_delete(root->right, s->key);
    }
    return root;
}
```

**工程注意**：上面的插入函数在内存分配失败时返回 NULL，简单递归写法可能把原子树指针覆盖为 NULL。严谨工程接口应返回状态码并通过二级指针修改根，或在递归中保留原子树指针；考试理解重点是插入位置与 BST 性质。实际使用时还需提供后序释放整棵树的函数。

### 删除三种情况

| 目标结点 | 操作 | 必须保持的性质 |
|---|---|---|
| 叶结点 | 父指针置空并释放 | 其余结点次序不变 |
| 仅一个孩子 | 父结点直接接上孩子 | 子树整体上移 |
| 两个孩子 | 用中序后继/前驱替换，再删除替代结点 | 中序序列仍有序 |

### 跟踪练习

依次插入 `50, 30, 70, 20, 40, 60, 80`，删除 50：中序后继为 60。根关键字替换为 60 后，原结点 60 从右子树中删除。最终中序序列为 `20,30,40,60,70,80`。
