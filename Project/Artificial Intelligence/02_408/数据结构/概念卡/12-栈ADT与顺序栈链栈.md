# 概念卡 12｜栈 ADT、顺序栈与链栈

## 核心定义
栈是限定仅在一端（栈顶）进行插入和删除的线性表，遵循后进先出（LIFO）。ADT 描述操作语义，不限定底层必须用数组还是链表。

| 操作 | 语义 | 常见复杂度 |
|---|---|---:|
| InitStack | 初始化空栈 | O(1) |
| Push(x) | 将 x 放到栈顶 | O(1) |
| Pop() | 删除并返回栈顶 | O(1) |
| GetTop() | 读取栈顶但不删除 | O(1) |
| StackEmpty() | 判断是否为空 | O(1) |

### 顺序栈
常见约定 A：top=-1 表示空栈，入栈先 ++top 再写入，出栈先读取再 top--。另一种约定以 top=0 表示栈顶元素个数。两种写法都可行，但初始化、判空、判满和操作顺序必须成套一致。

### 链栈
通常以链表头部作为栈顶，Push 头插、Pop 头删，均为 O(1)。动态分配结点，不代表空间无限；还需处理分配失败和释放结点。

### 共享栈
两个栈的栈底分别位于共享数组两端，栈顶向中间增长。常见判满条件 top1+1==top2。它改善空间利用率，但总容量仍受数组大小限制。

## 五大经典学习法
### 1. 费曼学习法
把栈解释成一摞盘子：只能从最上面放入和拿走。复述时必须解释为什么最后放入的元素最先出来，并指出“只能在栈顶操作”才是栈的限制条件。

### 2. 西蒙学习法
拆成三个知识块：①ADT 操作语义；②顺序栈的下标与边界；③链栈/共享栈的存储差异。先掌握 Push/Pop，再比较实现，最后分析空间与异常情况。

### 3. SQ3R 阅读法
- Survey：浏览 ADT 操作表和两种存储结构。
- Question：top 表示下标还是元素个数？满栈条件如何变化？
- Read：逐行跟踪 Push、Pop 的状态变化。
- Recite：不看代码写出空栈入栈、单元素出栈。
- Review：当天、次日、第 3 天和第 7 天重写边界判断。

### 4. 番茄工作法
番茄 1（25 分钟）：手算 4 组 Push/Pop；番茄 2（25 分钟）：分别实现顺序栈和链栈；每轮休息 5 分钟。验收：空栈、满栈、单元素栈均通过测试。

### 5. 康奈尔笔记法
| 线索 | 笔记 |
|---|---|
| 栈的原则 | LIFO，只在栈顶插入和删除 |
| GetTop 与 Pop | 前者只读，后者删除并返回 |
| 顺序栈边界 | 依赖 top 的定义，不能混用两套约定 |
| 链栈复杂度 | 头插、头删均 O(1) |
| 共享栈判满 | 两栈顶相邻时空间耗尽 |

**总结：** 栈的本质是受限线性表；ADT 定义“能做什么”，顺序栈和链栈定义“怎样存”。

## 自测与答案
1. 空栈依次 Push(2)、Push(5)、Pop、Push(7)，栈顶是什么？**答：7。**
2. top=-1 表示空栈时，第一次入栈的下标是多少？**答：0。**
3. GetTop 是否改变栈状态？**答：不改变。**
4. 链栈头插和头删的时间复杂度？**答：均为 O(1)。**
