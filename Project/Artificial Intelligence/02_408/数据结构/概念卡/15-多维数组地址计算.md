# 概念卡 15｜多维数组地址计算：行优先与列优先

## 核心公式
数组连续存储，地址计算分两步：先把多维下标换算成线性元素偏移，再乘元素字节数。

二维数组 A[l1..u1][l2..u2]，第二维长度为 n：
- 行优先：偏移元素数 = (i-l1)×n + (j-l2)
- 列优先：偏移元素数 = (j-l2)×m + (i-l1)，m 为第一维长度
- 地址 = 首元素地址 + 偏移元素数 × 单元素字节数

三维数组按行优先，维度长度为 p、q、r，零起始下标 (i,j,k) 的偏移为 i×q×r+j×r+k。

## 解题流程
1. 写清各维度上下界，算出每一维长度（上界−下界+1）。
2. 确认行优先还是列优先。
3. 用相对下标替代原下标。
4. 计算线性偏移，再乘元素字节数。
5. 做单位检查：偏移元素数不能直接当字节数。

## 五大经典学习法
### 1. 费曼学习法
把二维数组想成按顺序排放的书架。行优先先跨过前面的整行，再走到当前行的列位置；列优先则先跨列。解释为什么“列数”决定行优先的整行跨度。

### 2. 西蒙学习法
拆成：维度长度、相对下标、存储次序、字节换算四步。先做二维行优先，再做列优先，最后扩展三维。每一步都单独检查单位。

### 3. SQ3R 阅读法
- Survey：先看行优先/列优先地址示意。
- Question：为什么不能直接用 i×n+j？下标不从 0 开始怎么办？
- Read：对公式中每个量标注“维度长度/相对下标/字节数”。
- Recite：闭卷推导二维两种存储公式。
- Review：当天 3 题，次日 2 题，第 3/7 天混合下标题。

### 4. 番茄工作法
番茄 1（25 分钟）：行优先 4 题；番茄 2（25 分钟）：列优先与三维 4 题；每轮休息 5 分钟。验收：每题先写维度长度和相对下标。

### 5. 康奈尔笔记法
| 线索 | 笔记 |
|---|---|
| 行优先跨度 | 每跨一行，跨过第二维长度 n 个元素 |
| 列优先跨度 | 每跨一列，跨过第一维长度 m 个元素 |
| 非零起始下标 | 必须减去下界得到相对下标 |
| 地址单位 | 元素偏移 × 每元素字节数 |
| 三维行优先 | i×q×r+j×r+k |

**总结：** 地址题不是背一个公式，而是将坐标按存储顺序线性化，再完成字节换算。

## 自测与答案
1. A[1..4][1..6] 行优先，求 A[3][5] 的元素偏移数。**答：(3−1)×6+(5−1)=16。**
2. 每个元素 2 字节，首地址 2000，地址是多少？**答：2032。**
3. B[0..2][0..3] 列优先，B[2][1] 的偏移数？**答：1×3+2=5。**
4. C[0..1][0..2][0..3] 行优先，C[1][2][3] 的偏移数？**答：1×3×4+2×4+3=23。**

**达标标准：** 能正确处理下标起点、维度长度、存储次序和字节单位。
