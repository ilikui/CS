# 37｜基数排序、稳定性与复杂度比较

## 基数排序
基数排序按关键字的各个位（或字符位）依次进行稳定的分配与收集。常见 LSD 从低位到高位处理；每一趟必须稳定，才能保留前面位次建立的次序。

## 典型复杂度
设 n 为记录数、d 为处理位数、r 为每位可能取值范围：
- 时间 O(d(n+r))；
- 辅助空间 O(n+r)。
具体复杂度依关键字表示、桶实现和位数而定。

## 稳定性
稳定排序保证：若两个记录关键字相等，排序后它们的相对次序不变。
典型稳定算法：直接插入、冒泡、归并，以及每趟稳定分配收集的基数排序。
典型不稳定算法：希尔、快速、简单选择、堆排序。

## 对比思路
比较排序算法时至少检查：最好/平均/最坏时间、辅助空间、稳定性、是否原地、输入有序程度、关键字特点。不能只背一个复杂度数字。

## 五法学习
1. **费曼**：基数排序像先按个位排队，再按十位排队；每次都要保留同一桶内原来的先后顺序。
2. **西蒙**：拆为关键字位数、分配、收集、稳定性定义、复杂度参数、算法比较维度。
3. **SQ3R**：浏览排序总表；提问“为什么每一趟都稳定”；精读 LSD 示例；合上资料手算；隔日构造稳定性反例。
4. **番茄**：25 分钟完成一组三位数基数排序和一张复杂度/稳定性对照表，休息 5 分钟复核。
5. **康奈尔**：左栏写“稳定/原地/d/r/最好平均最坏”，右栏记录定义与条件，页底总结排序选择必须结合数据特征。

## 易错边界
- 基数排序不是比较排序；其复杂度不能简单套比较排序下界。
- 每趟分配收集必须稳定。
- 稳定性与空间复杂度是不同维度。
- 希尔排序复杂度依增量序列；快排最坏 O(n²)；堆排序建堆 O(n)、整体 O(n log n)。

## 自测
1. 稳定性定义是什么？
2. 基数排序典型时间复杂度中 d、n、r 分别代表什么？
3. 列举四种典型稳定排序。

**答案**：1. 相同关键字记录的相对次序保持不变；2. 位数、记录数、每位取值范围；3. 直接插入、冒泡、归并、稳定实现的基数排序。

## C 语言实现：LSD 十进制基数排序

下面实现面向**非负整数**，按个位、十位、百位……进行稳定计数分配。若需要支持负数，应先设计负数与非负数的分组/偏移策略，不能直接把本实现当作完整的 signed int 通用排序。

```c
void radix_sort_nonnegative(int a[], int n) {
    if (n <= 1) return;
    int max_value = a[0];
    for (int i = 1; i < n; ++i)
        if (a[i] > max_value) max_value = a[i];

    int *out = (int *)malloc((size_t)n * sizeof(int));
    if (out == NULL) return; /* 实际工程中宜把失败状态返回给调用者 */

    for (int exp = 1; max_value / exp > 0; ) {
        int count[10] = {0};
        for (int i = 0; i < n; ++i)
            ++count[(a[i] / exp) % 10];
        for (int d = 1; d < 10; ++d)
            count[d] += count[d - 1];
        /* 从右向左放置，保持本趟稳定性 */
        for (int i = n - 1; i >= 0; --i) {
            int digit = (a[i] / exp) % 10;
            out[--count[digit]] = a[i];
        }
        for (int i = 0; i < n; ++i) a[i] = out[i];
        if (exp > max_value / 10) break; /* 防止 exp *= 10 溢出 */
        exp *= 10;
    }
    free(out);
}
```

使用该代码需包含 `<stdlib.h>`。稳定性的关键不是“用了计数数组”本身，而是按原序从右向左放置，并使用前缀和确定稳定位置。

### 逐趟分配收集

对 `[170, 45, 75, 90, 802, 24, 2, 66]`：

| 趟次 | 按位 | 收集后的序列 |
|---|---|---|
| 1 | 个位 | 170, 90, 802, 2, 24, 45, 75, 66 |
| 2 | 十位 | 802, 2, 24, 45, 66, 170, 75, 90 |
| 3 | 百位 | 2, 24, 45, 66, 75, 90, 170, 802 |

每一趟都必须稳定，才能在处理更高位时保留低位已经建立的相对顺序。

**边界测试**：空数组、单元素、全 0、含多个相同值、不同位数混合；负数不属于本函数支持范围。若输入可能含负数，必须扩展算法并在接口文档中明确约束。

### 真题变式

设两个记录关键字分别为 21A、21B，原序 A 在 B 前。稳定的每趟分配收集必须保证同一数字桶内 A 仍在 B 前；若任一趟反向收集或随意重排桶内元素，最终整体稳定性就无法保证。

### 五法强化任务

- **费曼**：解释为什么先排低位、再排高位，以及桶内为何不能乱序。
- **西蒙**：拆为最大位数、计数、前缀和、稳定放置、回写。
- **SQ3R**：浏览三趟结果，提问“为何从右向左”，精读计数数组含义后自己复写。
- **番茄**：25 分钟完成一组三位数手算与一组边界测试，休息 5 分钟检查稳定性。
- **康奈尔**：左栏记录 d/r/LSD/稳定，右栏写每趟结果与空间复杂度，页底总结本实现只支持非负整数。
