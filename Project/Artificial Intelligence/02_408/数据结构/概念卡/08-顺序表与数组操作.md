# 顺序表与数组操作

> 408 数据结构 · 第 02 章原子化概念卡。五法学习 + 独立自测。

## 核心定义

顺序表用一组地址连续的存储单元依次存放线性表元素，支持随机访问。C 语言中通常用数组保存数据，并用 length 记录当前表长。

## 操作与复杂度

| 操作 | 核心步骤 | 时间 |
|---|---|---|
| 按位序取值 | data[i-1] | O(1) |
| 表尾插入 | 写入 data[length] | O(1)（容量允许） |
| 表头/中间插入 | 元素整体后移 | O(n) |
| 表尾删除 | length-- | O(1) |
| 表头/中间删除 | 后续元素前移 | O(n) |
| 按值查找（无序） | 逐项比较 | O(n) |

位序从 1 开始，数组下标从 0 开始。插入时从后向前移动，避免覆盖未移动元素；删除时从前向后移动后续元素。

## 五法学习

### 费曼学习法
顺序表像一排连续编号的储物柜：按编号能直接到达某个柜子；若在中间增加一个柜子，后面的物品可能都要向后挪。

复述：为什么访问第 i 个元素是 O(1)，而中间插入是 O(n)？表尾插入为什么可能是 O(1)？

### 西蒙学习法
分为地址定位、插入移动、删除移动、容量边界四块。先掌握 i 与 i-1 的映射，再训练循环方向。练习：画出 [10,20,30,40] 在第 2 位插入 15 的移动顺序。

### 康奈尔笔记
| 线索 | 笔记 |
|---|---|
| 随机访问？ | 连续存储，可由基址和下标计算地址 |
| 位序转换？ | data[i-1] |
| 插入移动方向？ | 从后向前 |
| 删除移动方向？ | 从前向后 |
| 插入复杂度？ | 表尾 O(1)，表头/中间 O(n) |
| 删除复杂度？ | 表尾 O(1)，表头/中间 O(n) |

页底总结：顺序表的强项是随机访问，代价是插入删除可能搬移元素。复杂度必须结合具体位置分析。

## 自测
1. 长度 n 的顺序表在第 1 位插入，需要移动多少个元素？——n 个。
2. 删除第 i 位后，需要移动多少个元素？——n-i 个。
3. GetElem 的位序到数组下标如何转换？——i-1。
4. 顺序表中间插入的时间复杂度？——O(n)。

掌握标准：能独立实现取值、插入、删除；下标无越界；移动方向正确；能计算移动次数。
