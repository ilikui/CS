# 34｜冒泡排序与快速排序

## 冒泡排序
反复比较相邻元素，若次序错误则交换；一趟后最大（或最小）元素到达边界。若某趟没有交换，可提前结束。
- 最好 O(n)（带交换标志），平均/最坏 O(n²)。
- 辅助空间 O(1)，稳定。

## 快速排序
选择枢轴，将序列划分为小于枢轴和大于枢轴的两部分，再递归排序子区间。
- 平均 O(n log n)，最坏 O(n²)。
- 最坏情况：枢轴持续落在极端位置，划分严重不平衡。
- 原地划分常见；递归栈平均 O(log n)，最坏 O(n)。
- 通常不稳定。

## 例题
对 [4,1,3,2]，若枢轴取首元素 4，第一次划分后 4 会落在最终位置，其左侧子序列继续递归。具体中间序列依赖划分实现，答题需说明采用的 partition 方案。

## 五法学习
1. **费曼**：冒泡像相邻交换把极值推到边界；快排像选一个分界标尺，把数据分到两边后递归处理。
2. **西蒙**：拆为比较/交换、趟次边界、枢轴选择、划分正确性、递归规模。
3. **SQ3R**：浏览代码；提问“枢轴怎样确定最终位置”；精读边界更新；合上资料手算；隔日改变枢轴策略。
4. **番茄**：25 分钟完成两组冒泡和两组快排分区，休息 5 分钟后分析最坏划分。
5. **康奈尔**：左栏写“趟次/枢轴/partition/最好平均最坏”，右栏记录状态，页底总结快排性能取决于划分平衡度。

## 易错边界
- 快排每趟结果依赖枢轴和划分实现，不可把某一种过程当成唯一序列。
- 冒泡的 O(n) 最好情况依赖提前结束标志。
- 快排平均 O(n log n) 不意味着最坏也如此。
- 稳定性要看相等关键字记录是否可能改变相对顺序。

## 自测
1. 冒泡排序最好情况的时间复杂度（带提前结束）？
2. 快速排序最坏情况是什么？
3. 快速排序通常稳定吗？

**答案**：1. O(n)；2. O(n²)，划分持续极端不平衡；3. 通常不稳定。

## C 语言实现与分区跟踪

### 冒泡排序（带提前结束）

```c
void bubble_sort(int a[], int n) {
    for (int end = n - 1; end > 0; --end) {
        int swapped = 0;
        for (int j = 0; j < end; ++j) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;
    }
}
```

相等时不交换（使用 `>`），所以该实现稳定。若某趟没有交换，说明当前序列已有序，可以提前终止。

### 快速排序（Lomuto 分区，末元素作枢轴）

```c
int partition(int a[], int low, int high) {
    int pivot = a[high];
    int i = low - 1;
    for (int j = low; j < high; ++j) {
        if (a[j] <= pivot) {
            ++i;
            int t = a[i]; a[i] = a[j]; a[j] = t;
        }
    }
    int t = a[i + 1]; a[i + 1] = a[high]; a[high] = t;
    return i + 1;
}

void quick_sort(int a[], int low, int high) {
    if (low >= high) return;
    int p = partition(a, low, high);
    quick_sort(a, low, p - 1);
    quick_sort(a, p + 1, high);
}
```

该版本便于教学，但对已有序或大量重复元素的输入可能表现较差；工程实现可考虑随机枢轴、三数取中、三路划分或小区间插入排序优化。优化能降低退化概率或改善常见输入表现，不改变经典快排最坏时间可达 O(n²) 的结论。

### 分区过程示例

对 `[4, 1, 3, 2]` 使用上述 Lomuto 分区，枢轴为末元素 2：

| 操作 | 数组状态 | 说明 |
|---|---|---|
| 初始 | 4, 1, 3, 2 | pivot=2 |
| 扫描 4 | 4, 1, 3, 2 | 4 大于枢轴，不移动 |
| 扫描 1 | 1, 4, 3, 2 | 小于等于枢轴，交换到左区 |
| 扫描 3 | 1, 4, 3, 2 | 3 大于枢轴 |
| 枢轴归位 | 1, 2, 3, 4 | 枢轴最终下标为 1 |

**边界测试**：`n=0` 时不要调用 `quick_sort(a, 0, -1)` 以外的非法区间；单元素区间直接返回；全相等数组会暴露该简单分区方案的性能弱点。

### 真题变式

给出一趟快排后的数组，不能只凭数组外观猜测唯一过程。必须先说明枢轴选择和 partition 规则；不同实现可能产生不同中间序列，但都应满足左侧元素不大于枢轴、右侧元素不小于枢轴的分区性质（具体等号归属由实现决定）。
