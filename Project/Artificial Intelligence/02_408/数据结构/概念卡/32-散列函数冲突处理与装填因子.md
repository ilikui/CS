# 32｜散列函数、冲突处理与装填因子

## 一句话定义
散列查找用散列函数把关键字映射到表地址；不同关键字映射到同一地址时发生冲突。

## 核心公式
散列地址：H(key)∈[0,m−1]。
装填因子：α=n/m，其中 n 为记录数，m 为散列表长度。

## 冲突处理
- **开放定址**：所有记录存放在表内，通过探测序列寻找空位。
  - 线性探测：Hᵢ(key)=(H(key)+i) mod m。
  - 平方探测：按平方偏移探测，具体正负序列依定义。
  - 再散列：冲突时使用第二散列函数计算步长。
- **拉链法**：同一地址的记录组织为链表或桶。

## 性能理解
α 越大，表越拥挤，冲突通常越多；但平均查找长度还取决于散列函数、冲突策略和关键字分布。散列查找平均可接近 O(1)，最坏可能 O(n)。

## 例题
表长 m=11，H(key)=key mod 11，依次插入 22、33、44，采用线性探测：三者初始地址均为 0，最终放在 0、1、2。α=3/11。

## 五法学习
1. **费曼**：散列像按编号分柜；冲突就是两件物品被分到同一柜，需要探测下一个空位或在柜内挂链。
2. **西蒙**：拆为散列函数、冲突定义、开放定址、拉链法、装填因子与性能。
3. **SQ3R**：浏览探测序列；提问“冲突后地址如何变化”；精读插入顺序；遮住笔记手算；隔日更换表长练习。
4. **番茄**：25 分钟完成 3 道线性探测、2 道拉链法和 2 道装填因子题，休息 5 分钟。
5. **康奈尔**：左栏写“H(key)/冲突/探测/α”，右栏记录公式与状态表，页底总结性能受多个因素共同影响。

## 易错边界
- 线性探测要考虑模 m 回绕。
- 插入顺序会影响开放定址最终位置。
- 删除开放定址表中的记录不能随意置空，通常需要删除标记或重整，否则可能中断查找链。
- α 不是 ASL 的直接等式。
- 平均 O(1) 不等于最坏 O(1)。

## 自测
1. 表长 20、记录数 15，α 是多少？
2. 线性探测的下一个位置如何计算？
3. 散列查找最坏时间复杂度是多少？

**答案**：1. 0.75；2. (H(key)+i) mod m；3. O(n)。

## C 语言实现：线性探测与删除标记

开放定址表不能把“从未使用”和“曾经使用后删除”都记为空；否则查找可能在删除位置提前停止，漏掉后续探测位置的元素。

```c
#define M 11
enum { EMPTY, USED, DELETED };
typedef struct { int key, state; } Slot;

int hash_find(const Slot t[M], int key) {
    int home = ((key % M) + M) % M;
    for (int i = 0; i < M; ++i) {
        int p = (home + i) % M;
        if (t[p].state == EMPTY) return -1;
        if (t[p].state == USED && t[p].key == key) return p;
        /* DELETED 不能终止查找 */
    }
    return -1;
}

int hash_insert(Slot t[M], int key) {
    int home = ((key % M) + M) % M, first_deleted = -1;
    for (int i = 0; i < M; ++i) {
        int p = (home + i) % M;
        if (t[p].state == USED && t[p].key == key) return p;
        if (t[p].state == DELETED && first_deleted < 0) first_deleted = p;
        if (t[p].state == EMPTY) {
            int dst = first_deleted >= 0 ? first_deleted : p;
            t[dst].key = key; t[dst].state = USED;
            return dst;
        }
    }
    if (first_deleted >= 0) {
        t[first_deleted].key = key; t[first_deleted].state = USED;
        return first_deleted;
    }
    return -1; /* 表满 */
}
```

删除操作应将目标槽状态改为 `DELETED`，而不是 `EMPTY`。上面代码用非负模运算处理负关键字；若题目只给非负关键字，也可按题设简化。

### 冲突跟踪

表长 11，`H(key)=key mod 11`，依次插入 22、33、44：

| 关键字 | 初始地址 | 探测过程 | 最终位置 |
|---:|---:|---|---:|
| 22 | 0 | 0 空 | 0 |
| 33 | 0 | 0 冲突，1 空 | 1 |
| 44 | 0 | 0、1 冲突，2 空 | 2 |

此时装填因子 `α=3/11`。删除 33 后，查找 44 仍必须越过槽 1 的删除标记才能到达槽 2。

### 真题变式

线性探测的探测序列为 `(H(key)+i) mod m`。平方探测、双重散列的探测序列不同；题目指定哪种策略就必须按该策略逐步模拟，不能把线性探测结果套用过去。
