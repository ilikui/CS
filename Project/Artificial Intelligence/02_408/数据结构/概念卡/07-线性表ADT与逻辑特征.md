# 线性表 ADT 与逻辑特征

> 408 数据结构 · 第 02 章原子化概念卡。五法学习 + 独立自测。

## 核心定义

线性表是由相同数据类型的 n（n≥0）个数据元素构成的有限序列。n=0 时为空表。除首元素外，每个元素有且仅有一个直接前驱；除尾元素外，每个元素有且仅有一个直接后继。

## 关键概念

- **表长**：当前元素个数 n。
- **位序**：逻辑位置，通常从 1 开始。
- **空表**：n=0，仍是合法线性表。
- **前驱/后继**：逻辑上紧邻的前一个/后一个元素。
- **线性关系**：描述逻辑顺序，不意味着内存地址连续。

## 五法学习

### 费曼学习法
把线性表解释为排队队列：每个人有前后邻居，队伍可以为空，也可以只有一个人。人站在什么物理位置不改变队伍的逻辑顺序。

复述：为什么线性表可以由链表实现？为什么空表仍属于线性表？

### 西蒙学习法
拆成有限性、同类型、序列关系、位序四块。先识别首尾边界，再判断中间元素的唯一前驱/后继。练习：给出空表、单元素表、普通表，分别写出表长和前驱/后继定义域。

### SQ3R
- Survey：浏览线性表定义和序列示意图。
- Question：空表是否有效？位序从几开始？物理连续是否为必要条件？
- Read：精读定义中的“有限”“相同类型”“直接前驱/后继”。
- Recite：不看资料重写定义并画 n=0、n=1、n=3 三种情况。
- Review：第 1、3、7 天复述定义并做判断题。

### 康奈尔笔记
| 线索 | 笔记 |
|---|---|
| 线性表？ | 相同类型 n 个元素构成的有限序列 |
| 空表？ | n=0，仍属于线性表 |
| 首尾元素？ | 首元素无直接前驱，尾元素无直接后继 |
| 位序？ | 逻辑位置，通常从 1 开始 |
| 是否要求连续存储？ | 不要求，连续是顺序存储的特点 |

页底总结：线性表定义逻辑序列，不规定具体存储实现；答题时注意空表、单元素表和位序从 1 开始。

## 自测
1. n=0 是否为线性表？——是，空表。
2. 第一个元素有直接前驱吗？——没有。
3. 线性表是否要求物理地址连续？——不要求。
4. C 数组下标与线性表位序是否一致？——通常相差 1，数组从 0，位序从 1。

掌握标准：能写出完整定义，并能准确处理空表、单元素和首尾边界。
