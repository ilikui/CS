## 本卡覆盖

头插法、尾插法、单链表逆置、有序表合并、顺序表/链表操作复杂度比较，以及算法不变量和边界条件。

## 关键算法

**头插法：** 每个新结点插入头结点之后，最终顺序与输入顺序相反。n 个元素总建表时间 O(n)。

**尾插法：** 维护 tail 指针，每次接在尾结点之后并更新 tail。总建表时间 O(n)。

**单链表逆置：** 使用 prev、cur、next 三指针。每轮先保存 cur->next，再反转 cur->next，推进 prev 和 cur。时间 O(n)，辅助空间 O(1)。

**有序表合并：** 双指针分别扫描两个非递减序列，每次取较小者，最后复制剩余部分。长度 m、n 时，时间 O(m+n)，输出空间 O(m+n)。

## 五法学习

### 费曼学习法
逆置链表像把一列指向右边的箭头逐个掉头。每次掉头前必须先记住原来右边的结点，否则剩余链表就找不到了。

复述：next 临时变量为什么必须先保存？为什么合并有序表只需线性扫描？

### 西蒙学习法
拆成建表、逆置、合并、复杂度四块。先手画算法状态，再写伪代码，最后证明循环不变量并计算每个结点访问次数。

### 康奈尔笔记
| 线索 | 笔记 |
|---|---|
| 头插法？ | 新结点接到头结点后，输入次序被反转 |
| 尾插法？ | tail 指向当前尾结点，插入后更新 tail |
| 逆置三指针？ | prev、cur、next |
| 保存 next 的原因？ | 反转链接前保留未处理后缀入口 |
| 逆置复杂度？ | 时间 O(n)，辅助空间 O(1) |
| 有序表合并？ | 双指针，时间 O(m+n) |
| 循环不变量？ | 每轮开始时 prev 为已逆置前缀，cur 为未处理后缀 |

页底总结：链表算法先保护后继链接，再改变当前链接。正确性可用循环不变量解释；复杂度按每个结点被处理的次数分析。

## 自测
1. 头插法最终次序？——与输入顺序相反。
2. 尾插法如何避免每次从头遍历到尾？——维护尾指针。
3. 逆置链表需要哪三个指针？——prev、cur、next。
4. 两个有序表合并时间复杂度？——O(m+n)。
5. 逆置链表辅助空间？——O(1)。

掌握标准：能独立实现逆置与合并；能解释循环不变量；能覆盖空表、单结点和重复元素边界。
