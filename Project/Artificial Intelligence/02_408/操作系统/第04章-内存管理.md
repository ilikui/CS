## 02. 地址绑定与逻辑地址

程序中的地址通常先表现为逻辑地址/虚拟地址，经地址转换后得到物理地址。地址绑定可发生在编译时、装入时或运行时。

- 编译时绑定：装入位置已知，生成绝对地址。
- 装入时绑定：装入时确定地址，装入后通常不能任意移动。
- 运行时绑定：执行期间由硬件地址转换机制完成，可支持进程移动和虚拟存储。

## 03. 连续内存分配

连续分配为进程分配一段连续物理内存。常见方法：
- 单一连续分配；
- 固定分区；
- 动态分区：首次适应、最佳适应、最坏适应等。

动态分区会产生外部碎片；紧凑技术可移动进程以合并空闲空间，但有额外开销。分页主要解决外部碎片问题，但页内可能存在内部碎片。

## 04. 分页存储管理

逻辑地址拆分为页号与页内偏移：

$$
\text{页号}=\left\lfloor\frac{\text{逻辑地址}}{\text{页面大小}}\right\rfloor
$$

$$
\text{页内偏移}=\text{逻辑地址}\bmod\text{页面大小}
$$

页表将页号映射为物理页框号。物理地址：

$$
\text{物理地址}=\text{页框号}\times\text{页面大小}+\text{页内偏移}
$$

若页大小为 $2^k$ Byte，则页内偏移占 $k$ 位。页表项还可能包含有效位、保护位、修改位和访问位。

## 05. TLB 与多级页表

TLB 是页表项的高速缓存。地址转换时先查 TLB；命中可快速得到页框号，未命中再访问页表并按策略更新 TLB。

多级页表将页号拆成多个索引字段，按需访问下级页表，节省稀疏地址空间的页表存储。计算有效访问时间时，要明确 TLB 命中/未命中各需几次内存访问，以及是否包含 Cache。

## 06. 分段与段页式

分段按程序逻辑模块划分地址空间，段长可变。逻辑地址通常由段号与段内偏移构成；段表记录段基址和段长。

若段内偏移超出段长，则发生越界异常。分段便于逻辑保护与共享，但会产生外部碎片。

段页式先分段、再对每段分页，兼顾逻辑划分与离散分配，但地址转换层次更多。

## 07. 虚拟内存与请求分页

虚拟内存允许进程地址空间大于当前驻留物理内存。请求分页仅在页面被访问而不在内存时调入。

缺页处理基本过程：
1. 硬件检测页表有效位，触发缺页异常；
2. 操作系统检查访问是否合法；
3. 找空闲页框，若无则选择牺牲页；
4. 必要时将修改页写回外存；
5. 调入所需页面并更新页表/TLB；
6. 重新执行引发缺页的指令。

## 08. 页面置换算法

- OPT：置换未来最长时间不会访问的页面，是理论最优基准，不可在线实现。
- FIFO：置换最早进入内存的页面，可能出现 Belady 异常。
- LRU：置换最近最久未使用页面，利用时间局部性。
- Clock/Second Chance：用访问位近似 LRU，降低实现开销。

计算页面置换时，按访问序列逐步画出页框，明确缺页次数和置换对象。

## 09. 抖动与工作集

若进程频繁缺页，CPU 大量时间用于页面调入调出，称为抖动。工作集描述进程在某时间窗口内近期访问的页面集合。适当分配足够页框可降低抖动。

## 10. 常见失分点

1. 页号与页内偏移计算未统一字节/字单位。
2. 物理地址公式漏乘页面大小。
3. 混淆分页内部碎片与分段外部碎片。
4. TLB 命中/未命中有效访问时间模型漏算访问次数。
5. 页面置换时未区分访问命中与缺页。
6. FIFO 与 LRU 的替换依据混淆。
7. 缺页异常不等同于非法地址访问。

## 12. 自测参考答案

1. 页号 $\lfloor10000/4096\rfloor=2$；偏移 $10000\bmod4096=1808$。
2. $9\times4096+100=36964$ Byte。
3. 减少外部碎片；可能产生页内内部碎片。
4. OPT 看未来最晚使用；FIFO 看进入内存时间最早；LRU 看过去最长时间未使用。
5. 访问页面不在内存时触发；若访问合法，可调页恢复，不一定非法。
6. 频繁缺页导致系统大量时间用于页面换入换出、有效执行效率显著下降的现象。

## 14. 本章五大经典学习法｜内存管理

### 14.1 费曼学习法：把逻辑地址变成物理地址讲清楚

程序使用逻辑/虚拟地址，硬件和操作系统通过地址转换把它映射到物理内存。分页把地址空间切成固定大小的页，把物理内存切成同样大小的页框；页表负责把页号映射到页框号。

- **分页**：固定大小，便于离散分配，减少外部碎片，但最后一页可能有内部碎片。
- **分段**：按程序逻辑模块划分，段长可变，便于保护和共享，但可能产生外部碎片。
- **TLB**：页表项的高速缓存，减少地址转换所需的内存访问。
- **虚拟内存**：进程可拥有大于当前驻留物理内存的地址空间，按需调入页面。
- **缺页异常**：访问的页面不在内存时触发；访问合法时，操作系统调页后可重新执行指令。
- **页面置换**：内存无空闲页框时选择牺牲页，如 OPT、FIFO、LRU、Clock。

**费曼复述练习：**

1. 为什么页号和页内偏移要分别计算？
2. 为什么物理地址要用页框号乘页面大小再加偏移？
3. 分页与分段分别解决什么问题，又产生什么碎片？
4. TLB 命中为什么能减少访存次数？
5. 缺页异常为什么不等于非法地址访问？
6. FIFO 为什么可能出现 Belady 异常，而 LRU 的依据是什么？

**边界提醒：** 页面大小、地址单位（字节/字）、TLB 命中/未命中访问次数和缺页代价必须按题目口径计算。页面置换题要逐次更新页框状态，不能只凭算法名称猜结果。

### 14.3 SQ3R 阅读法：围绕地址转换和缺页提问

- **Survey 浏览：** 先看分页地址公式、页表/TLB 图、缺页流程和页面置换对照表。
- **Question 提问：** 页大小如何决定偏移位数？TLB 未命中是否等于缺页？分段越界如何判断？缺页异常如何返回？OPT 为什么只能作为理论基准？
- **Read 精读：** 对地址转换题标记页号、偏移、页框号和物理地址；对置换题逐次写出访问页、命中/缺页、牺牲页。
- **Recite 复述：** 合上资料，独立完成一题分页地址转换、一题 TLB 时间计算和一题 LRU 页面置换。
- **Review 复习：** 当天重算地址题，第 1 天重做 TLB，第 3 天重做页面置换，第 7 天复习碎片与抖动。

**自问清单：**

1. 页面大小为 2^k Byte，页内偏移占多少位？
2. 页表项中的有效位、修改位、访问位分别有什么作用？
3. TLB 命中和未命中各经过哪些访问？
4. 分段地址的段内偏移如何与段长比较？
5. 缺页异常处理为什么要检查访问是否合法？
6. 页面被修改后被置换，为什么可能需要写回外存？
7. 工作集如何帮助减少抖动？

| 番茄 | 25 分钟任务 | 可验收产出 |

### 14.5 康奈尔笔记法：内存管理线索卡

| 左侧线索 / 问题 | 右侧主体笔记 |
|---|---|
| 分页地址拆分？ | 页号=floor(逻辑地址/页面大小)，偏移=逻辑地址 mod 页面大小。 |
| 物理地址？ | 页框号×页面大小+页内偏移。 |
| 页内偏移位数？ | 页面大小为 2^k Byte 时，偏移占 k 位。 |
| 分页碎片？ | 主要减少外部碎片，但可能有页内内部碎片。 |
| 分段碎片？ | 段长可变，可能产生外部碎片；便于逻辑保护和共享。 |
| TLB？ | 页表项的高速缓存；命中减少页表访问开销。 |
| 缺页异常？ | 访问页面不在内存时触发；合法访问可调页后重试。 |
| OPT/FIFO/LRU？ | OPT 看未来最晚使用；FIFO 看最早进入；LRU 看过去最久未使用。 |
| Clock？ | 用访问位近似 LRU，降低精确维护开销。 |
| 抖动？ | 频繁缺页导致系统时间大量耗费在换入换出。 |
| 工作集？ | 某时间窗口内近期访问的页面集合，可用于估计进程需要的驻留页。 |

**页底总结：** 内存管理计算题的核心是地址分解和访问路径统计。先确认页面大小、地址单位和页表结构，再进行转换；页面置换题按访问序列逐步更新；缺页异常要区分“页面不在内存”和“访问本身非法”。

### 14.6 五法融合自测

1. 页面大小为 8 KiB，逻辑地址 20000 Byte，求页号和页内偏移。
2. 页框号 12、页面大小 4096 Byte、偏移 128，求物理地址。
3. 分页主要减少哪类碎片？页内可能产生哪类碎片？
4. TLB 未命中是否一定导致缺页？说明原因。
5. FIFO、LRU、OPT 分别依据什么选择牺牲页？
6. 为什么修改页被置换时可能需要写回外存？
7. 什么是抖动？工作集能提供什么帮助？
