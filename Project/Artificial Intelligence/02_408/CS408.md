# 计算机学科专业基础综合（408）

> 面向 2028 考研。当前以已公开的 2027 年考试大纲作为阶段性参照；2028 年大纲发布后逐项核对，不提前把未确认变化写成事实。

## 一、考试结构

| 科目 | 常见分值参考 | 复习重点 |
|---|---:|---|
| 数据结构 | 约 45 分 | 算法设计、复杂度、树与图、查找排序 |
| 计算机组成原理 | 约 45 分 | 数据表示、运算器、存储层次、CPU、流水线 |
| 操作系统 | 约 35 分 | 进程线程、同步互斥、内存、文件、I/O |
| 计算机网络 | 约 25 分 | 分层体系、数据链路、IP、TCP、应用层 |
| 合计 | 150 分 | 以当年官方考试说明为准 |

> 单科分值是常见复习参考，不应理解为每年固定的官方配分。考试形式、题量和范围以当年正式大纲为准。

## 五、五大经典学习法（全科强制规范）

**任何概念性问题均必须同时使用以下五种方法完成学习与讲解：**
1. **费曼学习法**：用自己的话解释概念、原理、例子和反例。
2. **西蒙学习法**：拆分知识块、先修关系、刻意练习与反馈。
3. **SQ3R 阅读法**：Survey 浏览、Question 提问、Read 精读、Recite 复述、Review 复习。
4. **番茄工作法**：默认 25 分钟专注 + 5 分钟休息，任务必须有可验收产出。
5. **康奈尔笔记法**：线索问题、主体笔记、页底总结与错因复盘。

统一执行细则见[五大经典学习法-408统一模板](./五大经典学习法-408统一模板.md)。各科章节对应的概念群和练习重点见上表中的“五法应用指南”。五种方法不能只写名称，必须针对当前概念给出具体学习动作。

## 六、推荐学习顺序

1. 数据结构：建立抽象数据类型、存储结构和算法复杂度基础。
2. 计算机组成原理：理解指令、CPU、存储器和 I/O 的硬件执行过程。
3. 操作系统：把进程调度、虚拟内存、文件和设备管理与硬件联系起来。
4. 计算机网络：按分层结构学习协议、寻址、路由和可靠传输。
5. 四科交叉复习：围绕“程序如何运行、数据如何存储、系统如何通信”建立联系。

## 七、统一笔记规范

每个知识点都按以下结构沉淀：概念与适用条件 → 工作原理 → 公式/算法 → 基础题与综合题 → 易错点 → 真题映射 → 五大经典学习法 → 复习卡片。未核验的真题年份、题号不得填写。

## 八、真题与资料规范

- 先按当年大纲确认范围，再做题；不要仅凭网课目录判断考纲。
- 优先保存自己的解题过程、知识总结和题目索引，不整本复制受版权保护的辅导书。
- 真题标签至少包含：科目、章节、题型、年份、难度、错因。
- 记录正确率、用时、是否独立完成，不用“看懂解析”代替掌握。
