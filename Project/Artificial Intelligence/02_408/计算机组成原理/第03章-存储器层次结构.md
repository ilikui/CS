## 02. 存储器层次结构

从 CPU 向外，典型层次包括寄存器、Cache、主存和外存。通常越靠近 CPU，速度越快、容量越小、单位成本越高。

局部性原理：
- 时间局部性：近期访问过的数据可能再次访问。
- 空间局部性：访问某地址后，附近地址可能很快被访问。

Cache 利用局部性，将主存中可能再次使用的块复制到更快的存储器中。

## 03. SRAM 与 DRAM

- SRAM：以触发器等电路保存信息，速度快、成本高、集成密度较低，常用于 Cache。
- DRAM：以电容存储信息，需要刷新，密度高、成本相对低，常用于主存。

DRAM 刷新会占用存储器访问资源；具体刷新方式按题目给出的集中刷新、分散刷新或异步刷新机制计算。

## 04. 主存芯片扩展

存储芯片容量通常表示为“存储单元数 × 每单元位数”。扩展方式：
- 位扩展：增加数据位宽，多个芯片并行输出。
- 字扩展：增加存储字数，使用地址译码选择芯片组。
- 字位同时扩展：先组合位扩展与字扩展。

地址线数量决定可寻址单元数。若按字节编址，地址空间为 $2^k$ 个字节（$k$ 位地址）。

## 05. Cache 基本概念

Cache 以块为单位与主存交换数据。CPU 访问时：
- 命中：所需块在 Cache 中；
- 未命中：需要从下一级存储器调入块；
- 命中率 $H$：访问命中的比例；
- 缺失率 $1-H$。

平均访问时间常用模型（忽略其他复杂因素）：

$$
T_{\text{avg}}=H T_C+(1-H)T_M
$$

若主存时间 $T_M$ 表示未命中总访问时间，公式如上；若题目给的是额外缺失代价，则应按“Cache 命中时间 + 缺失率 × 缺失代价”建模，先辨明口径。

## 06. Cache 地址映射

设主存地址被划分为标记、组号/行号、块内偏移。

### 直接映射

每个主存块只能映射到 Cache 中唯一一行。若 Cache 有 $2^s$ 行，块号对行数取模决定行号。

### 全相联映射

主存块可放入 Cache 任意一行，需要并行比较多个标记，硬件成本较高。

### 组相联映射

Cache 分为若干组，主存块先映射到固定组，再在组内任意放置。$E$ 路组相联表示每组有 $E$ 行。

地址拆分需根据主存地址位数、Cache 容量、块大小和相联度计算：
- 块内偏移位数：$\log_2(\text{块大小})$；
- 组数：$\text{Cache容量}/(\text{块大小}\times\text{相联度})$；
- 组号位数：$\log_2(\text{组数})$；
- 标记位数：总地址位数减去组号位数与块内偏移位数。

## 07. 替换策略与写策略

常见替换策略：
- LRU：替换最长时间未被访问的块；
- FIFO：替换最早进入的块；
- 随机：随机选择替换对象。

写策略：
- 写直达：Cache 与主存同时更新，控制简单但写流量较大；
- 写回：只更新 Cache，块被替换时再写回主存，需脏位；
- 写分配：写未命中时先将块调入 Cache；
- 不写分配：写未命中时直接写下一级存储器。

写策略可组合，需根据题目明确的策略判断访存过程。

## 08. 虚拟存储基础

虚拟存储器为进程提供逻辑地址空间，利用页表将虚拟页映射到物理页框。TLB 是页表项的高速缓存，用于加速地址转换。

缺页时操作系统需要调入页面，可能发生页面置换。有效访问时间需结合 TLB 命中、页表访问、缺页概率和缺页处理代价建模，不能忽略题目给出的层级关系。

## 09. 典型计算框架

Cache 地址拆分：
1. 统一容量单位并确认按字节还是按字编址。
2. 计算块内偏移位数。
3. 计算 Cache 行数或组数。
4. 计算组号位数。
5. 剩余高位为标记位。

平均访问时间：
1. 明确命中时间；
2. 明确未命中时总时间还是额外代价；
3. 乘以命中率/缺失率；
4. 检查单位一致。

## 10. 常见失分点

1. 混淆 SRAM 与 DRAM 的用途及刷新要求。
2. 将位扩展和字扩展弄反。
3. Cache 地址拆分遗漏块内偏移位。
4. 组相联中组数计算没有除以相联度。
5. 平均访问时间中把缺失总时间和额外代价混用。
6. 写回策略忘记脏位与替换写回。
7. 虚拟地址、物理地址、页号、页内偏移概念混淆。

## 11. 章节自测

2. 16 位地址按字节编址，可寻址空间是多少？
3. Cache 块大小为 64 Byte，块内偏移需要多少位？
4. Cache 容量为 32 KiB、块大小为 64 Byte、4 路组相联，Cache 有多少组？
5. 若地址总长 32 位，上题组号位数与标记位数分别是多少？
6. 写回策略为什么需要脏位？
7. Cache 命中率为 0.9，命中时间 2 ns，未命中总访问时间 50 ns，平均访问时间是多少？

## 12. 自测参考答案

1. SRAM 快、常用于 Cache，无需像 DRAM 那样周期刷新；DRAM 密度高、常用于主存，需要刷新。
2. $2^{16}=65536$ Byte，即 64 KiB。
3. $\log_2 64=6$ 位。
4. 行数 $=32\text{ KiB}/64\text{ B}=512$；组数 $=512/4=128$ 组。
5. 组号位数 $\log_2 128=7$；标记位数 $32-7-6=19$。
6. 脏位记录 Cache 块是否被修改，只有被修改的块在替换时才需写回。
7. $0.9\times2+0.1\times50=6.8$ ns。

## 14. 本章五大经典学习法｜存储器层次结构

### 14.1 费曼学习法：解释为什么计算机需要多级存储

CPU 运算速度很快，但大容量存储器通常较慢。如果所有数据都只放在高速小容量存储器中，成本会很高；如果只使用低成本大容量存储器，CPU 又会频繁等待。因此计算机采用寄存器、Cache、主存和外存构成存储层次。

- **时间局部性**：刚访问过的数据可能很快再次访问。
- **空间局部性**：访问某地址后，附近地址可能很快被访问。
- **Cache**：利用局部性，把可能再次使用的主存块放到更快的存储层。
- **SRAM/DRAM**：SRAM 快、贵、密度低，常用于 Cache；DRAM 需要刷新、密度高，常用于主存。
- **芯片扩展**：位扩展增加字长，字扩展增加存储单元数量。
- **Cache 映射**：决定主存块可以放到 Cache 的哪些位置；替换策略决定空间不足时淘汰谁。

**费曼复述练习：**

1. 为什么越靠近 CPU 的存储器通常越快、越小、单位成本越高？
2. 用生活例子解释时间局部性和空间局部性。
3. 为什么 SRAM 常用于 Cache、DRAM 常用于主存？
4. 位扩展与字扩展分别改变什么？
5. 直接映射、全相联和组相联的核心差别是什么？

**边界提醒：** Cache 命中率不等于 CPU 性能提升比例；平均访问时间要根据题目给出的命中时间、失效代价和计算口径推导。地址拆分必须先确认主存地址位数、块大小、Cache 容量和相联度。

### 14.2 西蒙学习法：拆分存储系统知识块

| 模块 | 内容 | 前置关系 | 达标练习 |
|---|---|---|---|
| A. 存储层次 | 寄存器、Cache、主存、外存、局部性 | 无 | 比较速度/容量/成本并解释局部性 |
| B. 存储介质 | SRAM、DRAM、刷新 | A | 判断用途与特性 |
| C. 主存组织 | 芯片容量、位扩展、字扩展、地址线 | B | 设计芯片扩展并计算地址范围 |
| D. Cache 组织 | 映射、地址字段、替换、写策略 | A、C | 拆分地址并判断命中位置 |
| E. 性能计算 | 命中率、失效率、命中时间、平均访问时间 | D | 完成 AMAT 计算并解释假设 |

**刻意练习顺序：** 先确定容量单位和地址位数，再计算块号/组号/块内偏移；最后分析命中、未命中与替换。每题画出地址字段分割图，不要直接套记忆公式。

### 14.3 SQ3R 阅读法：围绕映射和性能提问

- **Survey 浏览：** 先看存储层次图、SRAM/DRAM 对比、芯片扩展示意、Cache 三种映射图。
- **Question 提问：** 为什么 Cache 以块为单位交换？直接映射如何确定位置？全相联为什么需要比较更多标记？组相联如何折中？命中率变化怎样影响平均访问时间？
- **Read 精读：** 对每种映射写出地址字段：块内偏移、行/组索引、标记；对每个容量题标明单位和编址方式。
- **Recite 复述：** 合上资料，独立拆分一组 Cache 地址，画出命中与未命中过程，并推导平均访问时间。
- **Review 复习：** 当天重做地址拆分，第 1 天重做芯片扩展，第 3 天重做替换策略，第 7 天完成综合性能题。

### 14.4 番茄工作法：五个番茄完成存储器

| 番茄 | 25 分钟任务 | 可验收产出 |

| 1 | 存储层次与局部性 | 画出层次图并举出两类局部性例子 |
| 2 | SRAM/DRAM 与主存芯片扩展 | 完成 3 道位扩展/字扩展题 |
| 3 | Cache 地址拆分 | 完成直接映射、组相联各 2 题 |
| 4 | Cache 替换与写策略 | 比较 FIFO/LRU 等策略和写直达/写回 |
| 5 | 命中率与平均访问时间 | 完成 4 道性能计算并检查单位 |

每轮休息 5 分钟。遇到地址题，先把容量统一换算成字节或字，再计算位数；遇到平均访问时间题，先确认题目是否把失效代价定义为额外时间。

### 14.5 康奈尔笔记法：存储系统线索卡

| 左侧线索 / 问题 | 右侧主体笔记 |
|---|---|
| 存储层次的总体趋势？ | 越靠近 CPU 越快、容量越小、单位成本越高。 |
| 时间局部性？ | 最近访问的数据可能再次被访问。 |
| 空间局部性？ | 当前访问地址附近的数据可能很快被访问。 |
| SRAM 与 DRAM？ | SRAM 快、贵、无需周期刷新，常用于 Cache；DRAM 密度高、成本低，需要刷新，常用于主存。 |
| 位扩展/字扩展？ | 位扩展增加每个字的数据位数；字扩展增加可存储的字数。 |
| Cache 映射？ | 直接映射每个主存块只有一个候选行；全相联可放任意行；组相联限制在指定组内。 |
| 地址字段？ | 块内偏移定位块内字节/字，索引定位行或组，标记用于判断是否为目标主存块。 |
| 命中率？ | H=命中次数/总访问次数；失效率为 1−H。 |
| 平均访问时间？ | 按命中与未命中概率加权；具体公式要按题目对 miss penalty 的定义。 |
| 替换策略？ | 当目标组/行空间不足时，决定淘汰哪个块，如 FIFO、LRU 等。 |

**页底总结：** 存储层次通过局部性缓解速度与容量的矛盾。主存芯片题关注容量和位宽扩展；Cache 题关注地址字段、映射位置、命中/失效和替换策略；所有性能计算都要先确认单位和时间口径。

### 14.6 五法融合自测

1. SRAM 与 DRAM 的主要差别是什么？分别常用于哪一级存储？
2. 需要 16K×8 位存储器，使用 4K×4 位芯片，需要多少片？如何组合？
3. Cache 块大小为 16 B，块内偏移需要多少位？
4. 直接映射 Cache 有 64 行，主存块号 130 映射到哪一行？
5. 命中时间 1 ns、失效率 5%、未命中额外代价 40 ns，若 miss penalty 定义为额外代价，平均访问时间是多少？
6. 为什么组相联映射比直接映射冲突更少，但硬件比较逻辑更复杂？

**答案要点：**

- 第 1 题：SRAM 快、贵、无需刷新，常用于 Cache；DRAM 需刷新、密度高、成本低，常用于主存。
- 第 2 题：位扩展需要 2 片并联得到 8 位；字扩展需要 4 组；共 8 片。
- 第 3 题：log₂16=4 位。
- 第 4 题：130 mod 64=2，即第 2 行（按 0 起始编号）。
- 第 5 题：AMAT=1+0.05×40=3 ns。
- 第 6 题：组内有多个候选行降低映射冲突，但需要并行/多路比较标记并选择命中路。
