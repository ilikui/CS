## 02. 总线基本概念

总线是多个部件之间传输信息的公共通路。按传输信息可分为：
- 数据总线：传输数据；
- 地址总线：传输地址；
- 控制总线：传输读写、中断、时序等控制信号。

总线可按结构分为单总线、双总线、多总线；按数据传输方式分为并行总线与串行总线。总线宽度、时钟频率、传输方式共同影响性能。

## 03. 总线性能指标

若总线宽度为 $w$ bit，时钟频率为 $f$，每个时钟周期可传输一次数据，则理想带宽：

$$
B=\frac{w}{8}\times f
$$

若每次传输需要多个时钟周期或存在等待状态，应按实际传输周期修正。带宽单位常用 Byte/s，需注意 bit 与 Byte 换算。

## 04. 总线定时

- 同步定时：统一时钟控制，接口简单，适合速度匹配的部件。
- 异步定时：通过请求/应答等握手信号协调，适应速度不同的部件，但控制更复杂。

总线仲裁用于多个主设备同时请求总线时决定使用权。常见集中式仲裁与分布式仲裁。

## 05. I/O 接口

I/O 接口连接系统总线与外部设备，通常包含数据寄存器、状态寄存器和控制寄存器。接口完成数据缓冲、状态反馈、控制命令接收和信号转换。

编址方式：
- 统一编址：I/O 寄存器占用存储器地址空间；
- 独立编址：I/O 有独立地址空间和专门指令。

## 06. 程序查询、中断与 DMA

| 方式 | CPU 参与程度 | 典型特点 |
|:---|:---|:---|
| 程序查询 | 持续查询设备状态 | 简单但忙等 |
| 中断驱动 | 设备就绪时通知 CPU | CPU 可执行其他任务 |
| DMA | 控制器直接完成成块传输 | 降低 CPU 数据搬运开销 |

DMA 过程通常包括 CPU 初始化 DMA 控制器、DMA 申请总线、控制器传输数据、完成后通知 CPU。DMA 并非完全不需要 CPU 参与。

## 07. 中断系统

中断系统需要处理中断请求、优先级判定、中断响应、现场保护、执行中断服务程序和中断返回。中断屏蔽用于暂时禁止某些中断请求；中断嵌套取决于优先级与屏蔽设置。

## 08. 典型计算

若数据总线宽度为 32 bit，频率为 100 MHz，每周期传输一次，则理想带宽：

$$
B=32/8\times100\times10^6
=400\times10^6\text{ Byte/s}
$$

若题目给出总线事务需要多个周期，应按事务周期数折算。

## 09. 常见失分点

1. 混淆地址总线宽度与数据总线宽度。
2. 带宽计算忘记 bit 转 Byte。
3. 忽略总线事务所需多个周期与等待状态。
4. 同步与异步定时特点混淆。
5. 将统一编址与独立编址混淆。
6. 认为 DMA 不需要 CPU 初始化和完成处理。
7. 混淆设备中断与 DMA 数据搬运。

## 11. 自测参考答案

1. 数据总线、地址总线、控制总线。
2. $32/8\times50\times10^6=200$ MB/s（按十进制 MB 计）。

6. CPU 持续轮询设备状态，忙等消耗处理时间。

## 13. 本章五大经典学习法｜总线与 I/O

### 13.1 费曼学习法：解释 CPU 如何与外设交换数据

总线是计算机各部件共享的信息通路。数据总线传送数据，地址总线指出访问位置，控制总线传递读写、时序和中断等控制信息。I/O 接口位于系统总线与外部设备之间，负责缓冲数据、报告状态和接收控制命令。

- **程序查询**：CPU 不断询问设备是否就绪，容易忙等。
- **中断驱动**：设备就绪后通知 CPU，CPU 可先做其他工作，但仍要执行中断服务程序搬运/处理数据。
- **DMA**：CPU 初始化 DMA 控制器后，由 DMA 控制器在设备与内存间成块传输；传输完成后再通知 CPU。
- **同步定时**：双方按统一时钟节拍协调。
- **异步定时**：通过请求/应答握手信号协调不同速度的设备。

**费曼复述练习：**

1. 为什么总线需要数据、地址、控制三类信号？
2. 为什么 32 bit 总线宽度不等于每秒传输 32 Byte？
3. 为什么程序查询容易浪费 CPU 时间？
4. DMA 为什么不是“完全不需要 CPU”？
5. 同步定时和异步定时分别适合什么场景？

**边界提醒：** 总线理论带宽通常是假设每周期一次传输；真实带宽还受事务周期、等待状态、仲裁和协议开销影响。DMA 需要 CPU 配置传输参数，并在完成后处理中断/状态。

### 13.5 康奈尔笔记法：总线与 I/O 线索卡

| 左侧线索 / 问题 | 右侧主体笔记 |
|---|---|
| 三类总线？ | 数据总线传数据，地址总线传地址，控制总线传读写/时序/中断等信号。 |
| 理想带宽？ | 若宽度 w bit、频率 f、每周期一次传输，B=(w/8)×f Byte/s。 |
| 同步/异步定时？ | 同步依赖统一时钟；异步通过请求/应答握手。 |
| 总线仲裁？ | 多个主设备竞争总线时决定使用权，可集中式或分布式。 |
| I/O 接口寄存器？ | 数据寄存器保存数据，状态寄存器反馈设备状态，控制寄存器接收命令/配置。 |
| 统一/独立编址？ | 统一编址将 I/O 寄存器纳入存储器地址空间；独立编址有专门 I/O 地址空间和指令。 |
| 程序查询？ | CPU 持续轮询状态，控制简单但忙等。 |
| 中断驱动？ | 设备就绪后请求中断，CPU 响应并执行服务程序。 |
| DMA？ | CPU 初始化参数，DMA 控制器直接完成成块传输，结束后通知 CPU。 |
| DMA 需要 CPU 吗？ | 需要初始化和完成处理，不是完全脱离 CPU。 |

**页底总结：** 总线题关注信号类型、传输周期和带宽；I/O 题关注接口寄存器与编址；传输方式题关注 CPU 参与程度。程序查询忙等最多，中断驱动以事件通知 CPU，DMA 负责成块数据搬运。

### 13.6 五法融合自测

1. 64 bit 数据总线每周期传输一次，频率 80 MHz，理想带宽是多少？
2. 地址总线有 20 根地址线，按字节编址，可寻址空间是多少？
3. 同步定时和异步定时分别依靠什么协调传输？
4. 统一编址与独立编址的核心区别是什么？
5. 程序查询方式为什么会产生忙等？
6. DMA 传输前 CPU 需要做哪些工作？
7. 32 bit 数据总线、50 MHz，每次总线事务需要 2 个周期，忽略其他开销，理想有效带宽是多少？

**答案要点：** 1. 64/8×80×10⁶=640 MB/s；2. 2²⁰ Byte=1 MiB；3. 统一时钟与请求/应答握手；4. I/O 寄存器是否占用存储器地址空间；5. CPU 不断检查设备状态；6. 配置源/目的地址、传输长度、方向和启动 DMA；7. 32/8×50×10⁶/2=100 MB/s。
