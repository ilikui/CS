# 第 05 章｜CPU

> 408 · 计算机组成原理。CPU 由运算器与控制器等部分构成。重点掌握数据通路、控制信号、指令周期、中断、微程序控制与流水线。

## 02. 运算器与控制器

运算器完成算术逻辑运算，常见部件包括 ALU、通用寄存器、状态寄存器等。控制器负责取指、译码、发出控制信号并协调部件工作。

控制器可采用硬布线控制或微程序控制。硬布线控制由逻辑电路产生控制信号，速度较快但设计复杂；微程序控制通过微指令序列产生控制信号，易于修改但存在微指令访问开销。

## 03. 数据通路

数据通路由寄存器、ALU、内部总线、多路选择器等组成。控制信号决定数据来源、运算类型、寄存器读写和结果去向。

分析数据通路题：
1. 明确当前指令语义；
2. 写出所需源操作数；
3. 确定 ALU 运算；
4. 标明结果写入位置；
5. 确定 PC 更新与访存动作。

## 04. 指令周期与控制信号

典型阶段包括取指、译码、执行、访存和写回。取指阶段通常根据 PC 访问指令存储器，并更新 PC；分支指令可能在执行阶段重定向 PC。

不同指令的控制信号不同。不要机械认为每条指令都需要数据存储器访问或寄存器写回。

## 05. 中断与异常

中断/异常使 CPU 暂停当前程序，转入相应处理程序，处理结束后按体系结构规则恢复执行。

- 中断通常由外部异步事件触发；
- 异常通常由当前指令执行引发，如缺页、非法指令、算术异常；
- 处理过程可能保存 PC、状态字和必要寄存器；
- 中断响应优先级、屏蔽与嵌套机制依体系结构而定。

## 06. 流水线基本原理

流水线将指令执行划分为多个阶段，使多条指令在不同阶段重叠执行。理想情况下，$k$ 段流水线执行 $n$ 条指令的周期数近似：

$$
T_{\text{pipe}}=(k+n-1)\tau
$$

其中 $\tau$ 为流水线时钟周期，假设各段平衡且无停顿。非流水执行若每条指令耗时 $k\tau$，则：

$$
T_{\text{nonpipe}}=nk\tau
$$

实际流水线会受阶段不平衡、寄存器开销和冒险影响。

## 07. 流水线冒险

- 结构冒险：硬件资源冲突；
- 数据冒险：指令间数据依赖，常见 RAW、WAR、WAW；
- 控制冒险：分支跳转改变后续取指路径。

解决方式包括资源复制、流水线停顿、数据前递、分支预测和延迟槽（体系结构相关）。

经典五级顺序流水线中，RAW 数据冒险最常见；WAR/WAW 是否出现与流水线是否乱序、寄存器重命名等设计有关。

## 08. 流水线性能

吞吐率表示单位时间完成的指令数；加速比为非流水执行时间与流水执行时间之比。

理想情况下，指令数足够大且阶段均衡时，加速比接近段数 $k$，但实际受冒险、停顿和额外开销影响。

## 09. 常见失分点

1. 混淆运算器和控制器职责。
2. 数据通路分析时漏掉寄存器读写控制。
3. 中断与异常的触发来源混淆。
4. 流水线理想公式忽略填充/排空周期。
5. 将流水线段数直接当作实际加速比。
6. 混淆结构、数据和控制冒险。
7. 将 RAW/WAR/WAW 适用范围绝对化。

## 11. 自测参考答案

1. ALU 执行算术逻辑运算；控制器译码指令并产生控制信号。
2. 指令执行过程中数据流经的寄存器、ALU、总线和选择器等硬件通路。
3. 中断通常来自外部异步事件；异常通常由当前指令执行引发。
4. $5+10-1=14$ 个周期。
5. 结构冒险、数据冒险、控制冒险。
6. 主要缓解数据冒险，尤其是 RAW 相关。

## 13. 本章五大经典学习法｜CPU、数据通路与流水线

### 13.1 费曼学习法：把 CPU 讲成一个协同工作的执行系统

CPU 不是单独的 ALU。运算器负责计算，控制器负责解释指令并发出控制信号，数据通路负责把寄存器、ALU、总线和多路选择器连接起来。每条指令都需要按自身语义选择数据来源、执行操作并决定结果写回位置。

- **数据通路**：像工厂中的传送带和加工设备，决定数据从哪里来、经过什么运算、最终送到哪里。
- **控制信号**：像生产调度指令，决定寄存器读写、ALU 功能和多路选择器选择。
- **中断**：通常由外部异步事件触发；**异常**：通常由当前指令执行引起。
- **流水线**：把指令执行分成多个阶段，让不同指令在不同阶段重叠执行。
- **流水线冒险**：资源冲突、数据依赖或分支路径不确定，可能阻碍理想重叠。

**费曼复述练习：**

1. 为什么 ALU 不能独立完成一条完整指令？
2. 用数据流说明一条加法指令如何从寄存器取数、经过 ALU、再写回。
3. 为什么中断与异常的触发来源不同，但都可能需要保存现场？
4. 为什么五级流水线执行 10 条指令不是简单的 50 个周期？
5. 为什么流水线段数为 5 不意味着实际加速比一定为 5？

**边界提醒：** 不同指令不一定经历所有流水线阶段；流水线理想公式假设各段平衡且无停顿；RAW/WAR/WAW 的出现与顺序/乱序执行、寄存器重命名等实现有关。

### 13.2 西蒙学习法：拆成五个 CPU 知识块

| 模块 | 内容 | 前置关系 | 达标练习 |
|---|---|---|---|
| A. 部件职责 | ALU、寄存器、状态寄存器、控制器 | 指令系统 | 画出部件关系图 |
| B. 数据通路 | 源操作数、ALU、结果写回、多路选择器 | A | 按指令画数据流 |
| C. 指令周期 | 取指、译码、执行、访存、写回、PC | B | 分析不同指令的阶段动作 |
| D. 中断/控制 | 中断、异常、现场保护、硬布线/微程序 | C | 对比触发源与处理过程 |
| E. 流水线 | 理想周期、吞吐率、冒险、前递、停顿、分支预测 | A—D | 画时空图并计算性能 |

**刻意练习路径：** 先根据指令语义写出数据流，再标控制信号；随后分析阶段时序，最后判断流水线冒险。每题都要写出“依赖关系→冲突发生阶段→是否能前递→是否需要停顿”。

### 13.3 SQ3R 阅读法：围绕数据流与冒险提问

- **Survey 浏览：** 先看 CPU 结构图、数据通路图、指令周期、流水线时空图和冒险分类表。
- **Question 提问：** 控制器和 ALU 的职责如何分工？数据通路为什么需要多路选择器？分支指令何时改变 PC？RAW 相关如何产生？前递为什么不能解决所有 load-use 情况？
- **Read 精读：** 对每条指令按阶段记录读哪些寄存器、执行什么运算、写回哪里；对相邻指令检查数据依赖和资源冲突。
- **Recite 复述：** 合上资料，画出一条寄存器加法指令的通路，再画出两条相关指令的流水线时空图。
- **Review 复习：** 当天重画数据通路，第 1 天复习中断/异常，第 3 天重做流水线冒险，第 7 天完成综合题。

**自问清单：**

1. ALU 的输入从哪里来？结果可能写到哪里？
2. PC 在取指、分支和异常时如何变化？
3. 为什么控制器必须生成控制信号？
4. 结构冒险的根本原因是什么？
5. RAW、WAR、WAW 分别表示什么读写顺序关系？
6. 数据前递把哪个阶段的结果送到哪个阶段？
7. 流水线填充与排空为什么会影响短指令序列的加速比？

### 13.4 番茄工作法：五个番茄完成 CPU

| 番茄 | 25 分钟任务 | 可验收产出 |
|---|---|---|
| 1 | 运算器、控制器和寄存器 | 画出 CPU 部件职责图 |
| 2 | 数据通路与控制信号 | 分析一条加法/访存指令的数据流 |
| 3 | 指令周期、中断与异常 | 对比两类事件并画处理流程 |
| 4 | 理想流水线周期与性能 | 完成 4 道周期数/加速比计算 |
| 5 | 三类冒险与解决方法 | 分析 3 组相关指令，标出前递/停顿 |

每轮休息 5 分钟。流水线题必须画时空图；只写周期数却不说明填充、排空和停顿条件，视为未完成。

### 13.5 康奈尔笔记法：CPU 线索卡

| 左侧线索 / 问题 | 右侧主体笔记 |
|---|---|
| ALU？ | 执行算术逻辑运算。 |
| 控制器？ | 取指、译码并产生控制信号，协调部件执行。 |
| 数据通路？ | 寄存器、ALU、内部总线、多路选择器等组成的数据流动路径。 |
| 指令周期？ | 常见取指、译码、执行、访存、写回；并非每条指令都经过全部阶段。 |
| 中断/异常？ | 中断通常由外部异步事件触发；异常通常由当前指令执行引发。 |
| 流水线理想周期？ | k 段执行 n 条指令，理想周期数 k+n−1，假设各段平衡且无停顿。 |
| 吞吐率？ | 单位时间完成的指令数；流水线填充后可提高吞吐率。 |
| 结构冒险？ | 多条指令同时争用同一硬件资源。 |
| 数据冒险？ | 指令间数据依赖，常见 RAW；WAR/WAW 受具体流水线实现影响。 |
| 控制冒险？ | 分支/跳转导致后续取指路径不确定。 |
| 解决方法？ | 资源复制、停顿、数据前递、分支预测等，具体适用条件依设计而定。 |

**页底总结：** CPU 题先明确指令语义，再沿数据通路追踪操作数和结果；流水线题要识别指令间依赖与资源冲突，最后根据前递、停顿和分支处理计算实际周期数。

3. 中断与异常的典型触发源分别是什么？

5. 结构冒险、数据冒险、控制冒险分别由什么原因造成？
6. 数据前递主要解决哪类冒险？

**答案要点：** 1. ALU 运算，控制器译码和发控制信号；2. 它们决定数据流和寄存器/存储器状态变化；3. 外部异步事件与当前指令执行；4. 6+12−1=17 周期；5. 资源冲突、数据依赖、控制流不确定；6. 主要缓解 RAW 数据相关；7. 实际存在填充/排空、阶段不平衡、冒险和停顿开销。
