## 6. 周统计口径
- 训练完成率 = 实际完成题数 ÷ 计划题数。
- 首次正确率 = 首次独立答对题数 ÷ 实际作答题数。
- 错题回访率 = 已完成回访的到期错题数 ÷ 到期错题总数。
- 有效学习时长不包含纯播放、走神和机械抄写。
- 统计时区与日期统一使用本地日期，避免跨日记录混乱。

## 9. 每日练习生成与发布规范（强制）

- 固定 15 题：英语二 3、高等数学（二）3、线性代数（二）3、408 3、思想政治理论 3。
- 每题必须标注：大纲章节、知识点、题型、难度（★—★★★）、预计用时、题源属性（原创 / 考点改编）。
- 每题题干之后立即附一个独立的 HTML 折叠答案区，格式如下；不得只在文末集中列答案，也不得省略解析：

```html
<details>
<summary>第 XX 题｜点击查看答案与解析</summary>

**参考答案：** 明确答案或完整参考作答。

**解析：** 必要推导、判断依据、关键公式/知识点及常见易错点。

</details>
```

- 每日必须恰好 15 个 `<details>` 块，编号与 01—15 题一一对应；选择题说明选项理由，计算题给出步骤，开放题写明参考要点/评分标准。
- 发布前核对题目与答案对应关系、数学计算、英语语法、408 术语与边界、政治教材表述；不能将前一题答案机械复制给后一题。
- 生成前检查最近 14 天练习；考点复现必须改变考查角度或题型，避免题干、选项、数字和答案重复。
- 大纲优先采用仓库招生资料目录中的 PDF。2027 大纲仅为暂行参考，必须明确等待 2028 官方大纲，不得称为 2028 正式要求。
- 每份文件应包含 YAML frontmatter、今日目标、预计总用时、知识地图、作答记录表、复盘与 D+1/D+3/D+7/D+14 复习栏。
- GitHub `main` 分支是唯一主归档；文件名固定为 `YYYY-MM-DD-每日基础练习.md`。写入后必须核验 commit SHA 并重新读取检查 15 题和 15 个折叠块。保留用户已有作答和批注。
- 日期与文件名统一按 Asia/Shanghai；未完成的作答、正确率和用时必须保持“待记录”，不得推断。

## 10. 答案必须达到“详细解答”标准（强制）

“隐藏答案”只表示默认折叠，不代表可以简写。每道题必须提供可供自学的完整讲解，不能只给选项、结论、公式名称或一句话提示。

- **英语题：** 给出正确选项/完整译文；解释句子主干、从句结构、关键词义、固定搭配、语法规则；逐项说明干扰选项为什么不合适；翻译题需按意群拆解并解释关键语法。
- **高等数学：** 写出使用的定义、定理或公式及适用条件；逐步列出代入、变形、计算和极限/积分过程；说明每一步依据；给出最终结果、验算或几何/概念解释；指出典型失分点。不得跳过关键中间步骤。
- **线性代数：** 展示行列式展开、矩阵运算、初等行变换、秩判断、方程组消元、特征值求解或二次型判别等具体步骤；解释所用性质与结论条件；唯一解/无穷多解/无解必须给出秩或行列式依据。
- **408：** 不只背结论。解释概念定义、工作机制/执行过程、关键字段或数据结构、适用条件；涉及计算题写出公式和逐步代入；涉及复杂度需说明最好/平均/最坏情形及依据；辨析易混概念。
- **政治：** 先给规范表述，再分点解释概念内涵、逻辑关系、历史背景或理论依据；材料题给出“材料信息→对应原理→分析论证→结论”的作答链条；列明得分点与常见遗漏。
- **开放题：** 明确写“参考答案/参考要点/评分标准”，按得分点逐条展开，不伪装成唯一答案。
- **篇幅要求：** 每题通常至少包含 3—6 个有实质内容的步骤/要点（简单词汇题可适当短，但仍须说明搭配、语境及干扰项）；综合计算、证明、材料题按完整解题链条展开，不以固定字数凑数。
- **质量闸门：** 若某题的解析无法让初学者仅凭该解析复现解题过程，则视为不合格，必须补写后才可推送。发布前逐题反向检查“题干问什么—答案是否回答—过程能否复现—结论是否正确”。
