## 6. 周统计口径
- 训练完成率 = 实际完成题数 ÷ 计划题数。
- 首次正确率 = 首次独立答对题数 ÷ 实际作答题数。
- 错题回访率 = 已完成回访的到期错题数 ÷ 到期错题总数。
- 有效学习时长不包含纯播放、走神和机械抄写。
- 统计时区与日期统一使用本地日期，避免跨日记录混乱。

## 7. 每日执行底线
时间不足时，优先完成：核心概念复习 → 当日基础题 → 错题回访 → 记录明日任务。不要为了维持连续打卡而虚报题量或完成状态。
