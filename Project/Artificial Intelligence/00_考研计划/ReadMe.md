## 04｜每日运行机制

1. **输入**：当天任务从月目标和周计划拆解，不临时堆砌资料。
2. **学习**：先理解知识，再做题；数学重推导与计算，408 重概念辨析与手写过程，英语重语境和篇章，政治重框架与准确表达。
3. **反馈**：每题标记正确/错误/猜对，错误必须归因。
4. **复习**：错题按 D+1、D+3、D+7、D+14 回访；未掌握则重新进入队列。
5. **沉淀**：只把稳定、有复用价值的结论写入学科笔记，计划目录保留链接和进度，不复制整篇知识内容。

## 05｜周复盘指标

| 指标 | 统计方式 | 复盘问题 |
|---|---|---|
| 计划完成率 | 已完成任务 ÷ 计划任务 | 是否计划过量？ |
| 有效学习时长 | 扣除走神与纯播放时间 | 时间是否投入到薄弱项？ |
| 训练正确率 | 首次独立正确数 ÷ 总题数 | 错误集中在哪些章节？ |
| 错题回访率 | 已回访错题 ÷ 到期错题 | 是否形成复习闭环？ |
| 输出质量 | 能否闭卷讲解/独立解题 | 是否真正掌握？ |

不以连续打卡天数代替学习质量。若某周完成率低于 70%，先缩小下周任务量并处理阻塞点，不通过简单加时补偿。

## 06｜知识与文件规范

- 章节笔记统一沉淀在对应学科目录；本目录只负责计划、索引、进度和复盘。
- 文件名建议：`YYYY-MM-DD-主题.md`；月度复盘：`YYYY-MM-月度复盘.md`。
- 公式统一使用 GitHub 可渲染的 LaTeX：行内 `$...$`，独立公式 `$$...$$`；避免把公式写成图片或不受支持的环境。
- 每道错题记录：来源、章节、题目/链接、首次错误原因、正确方法、复习日期、二次结果。
- 新增资源先判断是否解决具体问题；避免重复收藏和无目的刷课。
