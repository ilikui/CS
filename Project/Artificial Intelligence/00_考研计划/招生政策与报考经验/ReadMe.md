## 3. 信息来源优先级
1. 教育部及中国研究生招生信息网发布的正式政策。
2. 目标高校研究生院官网。
3. 目标学院官网及正式招生通知。
4. 官方发布的考试大纲、专业目录和复试办法。
5. 高校教师/招生负责人的公开说明。
6. 考生经验帖、论坛讨论和培训机构解读（仅作线索，必须回到官方文件核验）。

## 6. 重要原则
- 不把往年招生人数、分数线、报录比当作下一年度承诺。
- 不将第三方整理的“考试范围”当作官方大纲。
- 不确定的信息明确写“待核验”，不凭经验补齐。
- 官方文件更新后保留来源链接、发布日期和核验日期，必要时记录差异。
