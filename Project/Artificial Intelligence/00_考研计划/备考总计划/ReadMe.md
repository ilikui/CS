# 2028 考研备考总计划

> 以目标院校专业目录、考试科目和正式大纲为准。当前按数学二、英语二、408、思想政治四条主线规划；院校要求如有变化，优先修订本页。

## 阶段路线
| 阶段 | 主要任务 | 阶段验收 |
|---|---|---|
| 基础阶段 | 建立全科知识地图；教材/课程入门；每天稳定学习 | 能解释核心概念，完成基础题 |
| 强化阶段 | 专题训练、综合题、算法手写、真题分章练习 | 能独立完成典型题并说明方法 |
| 真题阶段 | 按年份限时训练，建立错题和薄弱点统计 | 成绩、用时和错因可追踪 |
| 冲刺阶段 | 查漏补缺、模拟考试、核心公式与概念回顾 | 稳定完成整套试卷并控制时间 |

## 每周学习闭环
1. 周初确定四科目标与可用时间。
2. 每天记录实际学习内容、题量、正确率和卡点。
3. 每周末统计完成率与薄弱章节。
4. 把错误分成概念、计算、方法、审题、记忆和时间管理。
5. 将错题安排在 1 天、3 天、7 天后回顾。

## 备考原则
- 以掌握程度而不是课程播放进度衡量学习效果。
- 一份知识笔记只保留一个主入口，其他位置使用链接，减少重复。
- 真题优先于无目的刷题；每道错题都要写清错误原因。
- 课程、教材、题目和笔记形成闭环，不追求收集资源数量。
