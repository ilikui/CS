# 2028 考研备考总计划

> 本页是全局策略与阶段验收标准。目标方向暂按人工智能规划，科目暂按数学二、英语二、408、思想政治理论执行；最终以 2028 年目标院校官方招生目录为准。

## 一、目标管理
- **结果目标**：完成目标院校/专业的报考准备，达到初试与复试要求。
- **能力目标**：数学能独立推导和计算，408 能解释原理并完成综合题，英语能读懂文章并准确表达，政治能建立框架并规范作答。
- **过程目标**：每天完成 15 题基础训练，周周复盘，月月验收；以掌握度而非学习时长或课程进度作为主要评价。

## 三、科目策略

### 数学二
- 高等数学与线性代数分开管理，按章节推进。
- 每个知识点形成“定义/定理—适用条件—典型方法—易错点—练习”五段笔记。
- 计算题保留完整步骤；错题标记概念、方法、计算、审题或书写问题。
- 理解公式推导与使用边界，避免只背结论。

### 408
- 四门课程分别建立知识地图：数据结构、计算机组成原理、操作系统、计算机网络。
- 对比易混概念，整理算法复杂度、组成原理计算过程、操作系统机制、网络协议分层。
- 算法题要求手写思路、伪代码/代码、复杂度和边界情况。
- 综合题按“题意拆解—知识定位—过程推导—结果校验”训练。

### 英语二
- 词汇按语境、词性、搭配和熟词僻义整理。
- 长难句先找主干，再识别从句、非谓语和逻辑关系。
- 阅读记录定位依据、干扰项类型和错因，不只抄译文。
- 翻译、写作、新题型与完形按阶段逐步加入，保持持续输出。

### 思想政治
- 基础阶段建立章节框架，不以过早大量背诵挤占数学和 408。
- 强化阶段重视选择题知识辨析和错项原因。
- 冲刺阶段结合当年时政与正式材料，训练观点、原理、材料对应关系。
- 时政内容标注年份与来源，旧年度材料不能直接当作当年结论。

## 四、每周学习闭环
1. 周初从月目标中选定可验收任务，给每科设定最低交付物。
2. 每天执行 15 题：英语二 3、高数 3、线代 3、408 3、政治 3。
3. 当天完成答案核对，记录首次正确率、用时、错因和待回访日期。
4. 周末统计任务完成率、各科正确率、错题回访率与实际薄弱章节。
5. 根据数据调整下一周，不用堆叠任务弥补未完成项。

## 五、错题复习机制
| 时间 | 动作 | 通过标准 |
|---|---|---|
| D0 | 标记错误原因并写出正确解法 | 能说明错在哪里 |
| D+1 | 不看答案重新完成 | 独立做对并解释 |
| D+3 | 变式或口述原理 | 能识别条件变化 |
| D+7 | 混合题中再次检索 | 能快速定位方法 |
| D+14 | 闭卷抽查 | 稳定掌握；否则重新排期 |

错因统一使用：概念不清、公式/定理误用、方法选择、计算失误、审题遗漏、记忆不牢、表达不规范、时间分配。

## 六、风险与调整
- **进度落后**：先保核心章节和真题主线，削减低收益资料，不盲目熬夜补时长。
- **正确率停滞**：暂停增加题量，回到定义、例题和错因分析。
- **资源过载**：每科保留一套主教材/主课程和一套主练习，其他资源仅用于解决具体疑问。
- **政策变化**：以报考年度官方通知为准，更新招生政策页和本页科目配置。
- **状态波动**：设置最低可执行任务，保持连续性；周复盘优先恢复节奏。
