## 月度验收原则
1. 每科至少有一个可检查的学习产出。
2. 章节结束必须有独立练习或闭卷复述，不以看完课程为完成。
3. 错题必须有复习结果；未通过的知识点顺延并明确优先级。
4. 月末用数据调整下月任务量，不追求表格全部打勾。
5. 2027 年官方大纲发布后，逐项映射章节，标记新增、删除和变化内容。
