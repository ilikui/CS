# 每周学习计划｜Weekly Sprint

> 每周是一轮可验收的学习迭代。先确定本周交付物，再拆到每天；计划应匹配实际可用时间，避免把待办清单当作学习成果。

## 1. 周计划看板
| 项目 | 本周目标 | 验收证据 | 状态 |
|---|---|---|---|
| 数学二·高数 | 章节/专题： | 独立完成题目；能讲解方法 | ⬜ |
| 数学二·线代 | 章节/专题： | 推导关键结论；完成典型题 | ⬜ |
| 408 | 数据结构/计组/操作系统/网络： | 概念辨析、算法或计算过程 | ⬜ |
| 英语二 | 词汇、阅读、长难句/翻译： | 阅读定位依据、词汇复现 | ⬜ |
| 思想政治 | 章节与知识框架： | 选择题与错项解释 | ⬜ |
| 错题回访 | D+1/D+3/D+7 到期题 | 回访结果与二次正确率 | ⬜ |

## 2. 每日基础训练配额
每天 15 题作为基础训练基线：

| 模块 | 每日题量 | 训练重点 |
|---|---:|---|
| 英语二 | 3 | 词汇/语法/阅读理解轮换 |
| 高等数学 | 3 | 概念、计算、典型题 |
| 线性代数 | 3 | 定义、性质、矩阵/向量计算 |
| 408 | 3 | 四门轮换，兼顾理解与应用 |
| 思想政治 | 3 | 概念辨析、选择题、时政识别 |

题量是基础训练结构，不代表所有题目难度相同。周计划可加入章节深度训练、真题和整套模拟；若时间不足，优先保证复盘质量。

## 3. 建议周节奏
| 日期 | 主要任务 | 当日收尾 |
|---|---|---|
| 周一 | 明确本周目标；数学主线推进；英语词汇 | 建立任务清单 |
| 周二 | 高数/线代专题；408 数据结构/计组 | 整理方法与错题 |
| 周三 | 数学综合练习；408 操作系统/网络 | 回访 D+1 错题 |
| 周四 | 英语阅读精练/翻译；数学薄弱点 | 归纳干扰项与计算错误 |
| 周五 | 408 综合与算法手写；政治章节训练 | 回访 D+3 错题 |
| 周六 | 本周专题巩固、真题/套题训练 | 统计正确率与用时 |
| 周日 | 补漏、错题回访、周测与复盘 | 制定下周计划 |

此节奏可按个人作息调整；周日应留出复盘时间，不把所有未完成任务机械堆到周末。

## 6. 计划质量规则
1. 每项任务必须有可检查的完成证据。
2. 一天安排 1—3 个重点任务，其余为维持性训练。
3. 同一薄弱点连续两次未通过，安排回到教材/课程重学。
4. 周计划完成率低于 70% 时，先减少任务量、定位阻塞，不直接加倍排课。
5. 学习时长只作辅助指标，独立解题、闭卷复述和错题回访才是主要验收。
